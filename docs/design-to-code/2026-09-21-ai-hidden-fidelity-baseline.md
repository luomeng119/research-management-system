# 当前交付界面基线：隐藏本地 AI

## 设计来源

以当前桌面端科研管理系统为界面基线，仅移除当前交付不再提供的本地 AI 信息和动作，不做布局重构。

## 需要核对的页面状态

| 页面 | 目标状态 |
| --- | --- |
| 登录页 | 保留本地安全运行说明，不宣称 AI 模型运行 |
| 领导介绍页 | 保留系统功能、数据流程和架构；移除 AI 专章、Qwen 名称和智能层 |
| 辅助工具首页 | 不显示 AI 文档校对或本地模型维护卡片 |
| 提案表单 | 不显示 AI 助手按钮或助手面板 |
| 科研报告来源/草稿/版本/选区页 | 保留人工上传、编辑、版本和导出；不显示生成、图片提取、选区建议或模型原稿动作 |
| 模型配置/状态直接 URL | 返回 404 |

## 对照方法

- 桌面视口：1440×900。
- 对关键页面执行登录后真实浏览器检查，搜索可见文本和可交互元素。
- 对直接 AI URL 检查 HTTP 404。
- 复核隐藏后页面没有明显空白容器、断裂标题或不可用主操作。

## 可接受变更

仅允许删除或条件隐藏 AI 相关卡片、按钮、专章、说明和后端入口；不得改变现有人工业务导航、字段、列表和报告编辑结构。
