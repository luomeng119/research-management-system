# 领导介绍页设计实现基线

## 设计来源

- 用户确认的结构：左侧清晰目录，右侧逐项图文介绍，顶部提供系统登录地址。
- 现有产品视觉变量：`design-tokens.css` 的暖白底、深海军文字、青绿色品牌色。
- 用户纠正后的图形范围：流程图、系统架构图、AI 作用边界图和模块关系图；不使用场景插画。

## 信息结构

左侧七项目录固定为：系统总览、执行流程、系统功能、数据流程、本地 AI、系统架构、交付结果。右侧一次展示一个章节，避免形成长文档滚动墙；目录点击、上一项/下一项按钮和键盘左右键均可切换。

每个章节最多包含一个标题、一句结论、三至五个平行要点和一张可编辑结构图。技术细节通过短标签、连线、层次图和状态卡表达。

## 视觉基线

- 1440×900：左侧目录约 280px，右侧主内容完整占据剩余区域；首屏不出现横向滚动。
- 1280×800：保持左右分栏，卡片和流程节点自适应收窄。
- 本次不包含移动端，页面只针对当前 Mac 与现场桌面投影环境。
- 结构图由 HTML/CSS 绘制，放大后文字和线条保持清晰，中文为可访问 HTML。
- 状态与层次通过颜色、图标和文本共同表达，不以颜色作为唯一信息来源。

## 对照方法

1. DOM 契约检查七个导航项、七个内容面板和双向登录链接。
2. Playwright/真实浏览器逐项点击并验证 `aria-selected`、活动面板和 URL hash。
3. 1440×900、1280×800 截图检查文字密度、裁切、溢出和焦点状态。
4. 扫描 HTML/CSS/JS，确认无 `http://` 或 `https://` 外部静态资源引用。

## 登录页基线

保留 `login-username`、`login-password`、`_csrf_token`、POST 提交和错误提示。左侧改为生成主图与业务价值，右侧保持登录任务聚焦，并增加指向介绍页的次级入口。
