# 无本地生成模型交付回滚说明

## 当前交付边界

当前版本默认 `AI_FEATURES_VISIBLE=False`、`AI_PROVIDER=DISABLED`，不加载本地生成模型，不展示相关入口。人工科研报告、版本、敏感词和 DOCX 导出独立运行。

## 代码回滚

如需撤销本轮代码改造，应从 Git 中选择本轮发布提交的父版本，在隔离分支恢复并重新执行全量测试。不得只恢复页面按钮而跳过服务与路由门禁，也不得在现行版本上临时改环境变量后直接发布。

## 模型能力恢复

已删除的项目模型文件不是源码制品，不能用 Git 回滚。以后恢复本地生成模型时，应重新完成模型选型、官方来源下载、哈希记录、单模型驻留、内存验证、功能门禁显式启用和独立验收，再形成新的发布版本。

## 数据与人工业务

本轮未迁移或删除 PostgreSQL 业务数据，也未改变人工报告、版本、敏感词和 DOCX 的数据合同。回滚前仍应执行数据库备份，并用相同版本迁移脚本验证结构兼容。

## GitHub发布回滚

公开仓库发布后若发现错误，可先将仓库临时设为私有，再在受控分支回退到已验证提交并重新执行交付检查。不得覆盖或删除现有 `ai-archives-research-platform` 仓库。
