# 领导介绍页与登录页实施及测试计划

## 交付目标

在本地 8893 应用中新增可直接汇报的图文介绍页，并将登录页优化为清晰、可信、便于进入系统的首界面。

## 实施顺序

1. 固化展示结构：总览、业务流程、系统功能、数据流程、本地 AI、系统架构、交付结果。
2. 使用 HTML/CSS 绘制流程图、架构图、模块关系图和 AI 作用边界图，所有文字可选择、可修改。
3. 新增公开只读路由、介绍页模板、独立 CSS 和 JS。
4. 优化登录页，并增加“了解系统”入口；保留所有安全和表单契约。
5. 增加路由、安全、离线资源、DOM 结构和交互契约测试。
6. 运行 Python 回归、前端静态检查和真实浏览器点击/登录验收。
7. 重启 8893 应用并确认介绍页、登录页和健康检查可访问。

## 回滚点

- 路由：从公开端点集合中删除介绍页端点，并删除注册路由。
- 页面：删除介绍页模板及专用静态资源，恢复登录模板备份。
- 运行：重启 8893 应用；数据库、模型和用户数据不需要迁移或回滚。

## AI 评估边界

本次不改变模型推理逻辑。介绍页只展示已验证能力；既有提案助手、整合报告草稿、选区措辞建议和图片提取结果统一增加 AI 标识。

## 验收矩阵

- 匿名访问介绍页返回 200，匿名访问业务页仍跳转登录。
- 七个目录项均可点击并定位到对应内容。
- 数据流程覆盖资料来源、入库与关联、插入、编辑、合并、删除、版本和输出。
- 页面无外部网络资源，图形全部由本地 HTML/CSS 绘制。
- 顶部登录链接和登录页介绍链接双向可达。
- `admin/admin` 可从优化后的登录页进入工作台。
- 1440×900 与 1280×800 桌面视口无横向溢出，键盘焦点清晰；移动端不在本次范围。
