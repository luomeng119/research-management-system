# 科研创新与项目管理系统产品设计与功能范围

版本：V1.1  
更新时间：2026-09-11  
状态：当前 Mac 本地演示版

## 1. 产品定位

系统面向小型科研单位，把分散的科研提案、论证记录、项目执行资料、专家与设备资源、报告版本和成果文件放进一条可追溯的业务主线。系统最终形成可持续完善的科研报告和可下载的 Word 文件。

当前验证使用“便携式野外试验环境数据采集终端研制”合成课题。合成资料用于验证功能和模型能力，不代表甲方真实科研数据。

## 2. 使用人员

| 人员 | 主要工作 |
| --- | --- |
| 管理员 | 登录系统、维护用户、维护敏感词库、查看模型状态并完成全部业务操作 |
| 业务用户 | 创建提案、上传资料、参与论证和项目执行、编辑报告并下载成果 |
| 领导或汇报对象 | 通过系统介绍页理解业务流程、功能范围、数据流和本地AI作用 |

当前演示账号为 `admin/admin`。

## 3. 核心功能

| 功能域 | 已实现能力 | 主要结果 |
| --- | --- | --- |
| 科研提案 | 新建、编辑、附件、AI字段建议、人工采纳 | 可进入论证的提案记录 |
| 论证与立项 | 论证记录、决定、提案与项目关联 | 正式科研项目 |
| 项目执行 | 进展、变更、成果、结题及历史记录 | 可追溯的项目过程 |
| 科研报告 | 多资料来源、图片提取、整合草稿、人工编辑、版本保存、Word导出 | 带来源与版本号的科研报告 |
| 文档管理 | 上传、文件夹上传、预览、关联、版本、下载和受控移除 | 可回到原件和固定版本的资料链 |
| 敏感词库 | 原词与代称、启用/禁用、JSON导入、预览、保存新版本和历史查看 | 确定性替换规则版本 |
| 科研资源 | 专家、设备、设备组、标准法规、模板和研制单位 | 项目可复用的支撑资源 |
| 辅助工具 | 通用表格、结构化业务单据、OCR、模型配置与状态 | 辅助业务数据与运行状态 |

## 4. 本地AI的有限作用

本地AI只进入需要理解或生成文字、图片内容的环节：

1. 科研提案字段建议。
2. 科研图片内容提取。
3. 多方资料整合为待确认的报告草稿。
4. 新资料加入后的报告修订建议。
5. 阅读报告时，对人工框选文字提供1至3条措辞建议。

模型结果必须由人核对和选择。系统不允许模型直接立项、直接覆盖报告版本、决定敏感词映射、认定科研结论或修改权限。

## 5. 程序负责的确定性能力

- 敏感词匹配与固定代称替换。
- 用户权限、登录和CSRF保护。
- 业务状态流转及项目关联。
- 文件编号、版本、哈希和来源快照。
- 报告版本保存、历史回读和DOCX导出。
- 操作审计、备份和恢复。

## 6. 当前交付成果

- 当前 Mac 可运行的本地系统。
- 固定端口、可观察的模型状态和管理员入口。
- 一套完整合成科研案例及多方资料。
- 已保存的报告历史版本。
- 一份经真实流程生成的含图科研报告 DOCX。
- 最终验收 Excel、回归记录、复核清单和启动说明。

## 7. 当前范围边界

本次不包含甲方真实数据导入、复杂Office文档无损往返编辑、会议会签、复杂权限矩阵、远程部署、Ollama迁移、FastAPI重构、RAG或多模型调度。移动端不在当前演示范围。
