# T06 科研提案纵向切片报告

## 实现结果

- 完成科研提案新建、分页列表、草稿编辑、附件关联、论证记录、暂缓、重新论证、退回补充和不立项闭环；会议结论仅作为来源类型，没有生成会议或审批对象。
- 提案正文仅草稿可编辑；状态只能通过显式业务动作流转。乐观锁、状态检查、决定写入与最小审计均在同一事务内。
- `ESTABLISH` 在 T06 明确返回 409，不伪造项目；立项将由 T08 原子创建项目、台账与决定。
- 处理决定使用“用户 + 路由 + 提案 + 幂等键”作用域；首次与重放的 HTTP 201 和完整 JSON 相同。
- 提案列表、论证历史和决定历史均提供可操作分页；服务端 `pageSize` 上限为 100，详情页每页 10 条。
- 附件复用 T04 `PROPOSAL + businessId`。`ESTABLISHED/REJECTED` 的上传、增加版本和归档在页面与通用 `FileService` 双层拦截，事务内再次加锁复核。
- API 统一列表 envelope，字段错误 `details` 数组化，超限请求保留 413 `PAYLOAD_TOO_LARGE`；中文状态和来源已进入页面。
