# T07 科研提案助手报告

## 实现结果

- 在提案编辑页接入轻量“科研提案助手”；AI 不是一级模块，不作立项、专家推荐或合规决定。
- 实现 DeepSeek/本地模型统一契约、严格 JSON 解码、单次请求、60 秒总截止、取消、错误降级和 512KB 响应上限。正式配置拒绝 DeepSeek，本地模型只允许字面回环地址且禁用代理/重定向。
- 只处理用户主动选择的文字和当前提案最多 3 个 UTF-8 纯文本附件；跨提案、归档、二进制、控制字符和超限内容均拒绝。DeepSeek 调用还要求用户明确确认本次输入已脱敏。
- 生成只保存临时草稿；只有用户勾选的字段才能在提案版本、草稿状态和审计同一事务中采纳。取消、超时、格式错误或审计失败不会改写提案。
- `0002_proposal_assistant` 如实保存 `LOCAL/DEEPSEEK` 来源和生成时提案版本；旧草稿回填为未知版本 `0` 且不可采纳。存在 DeepSeek 证据时拒绝有损降级，不静默删除。
- 冻结 20 条四类脱敏样本、数据集版本和 SHA-256；评分器拒绝 Fake Adapter 充当模型质量，并要求每条样本至少两名人工复核者。
