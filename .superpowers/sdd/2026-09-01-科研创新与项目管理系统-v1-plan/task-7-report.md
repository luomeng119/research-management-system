# T07 科研提案助手报告

## 实现与边界

- 提案编辑页内提供轻量助手；只整理用户主动选中的文字和最多 3 个当前提案 UTF-8 文本附件。AI 不成为一级模块，不作立项、专家推荐或合规决定。
- 开发期可在用户确认材料已脱敏后调用 DeepSeek；正式环境拒绝 DeepSeek，只允许回环地址本地模型。统一契约采用严格 JSON、稀疏字段和逐字段事实映射，不引入向量库、RAG、Agent 或自动重试。
- 生成结果只保存临时草稿；用户勾选并确认的字段才在版本校验、草稿状态和审计同一事务中采纳。取消、超时、格式错误、审计失败和空建议均不改写提案。
- NFKC 后仅含空白、控制/格式符或组合标记的内容均视为空；契约、提案必填、服务端采纳和 UI 使用一致规则。`missingInformation` 最多 6 项。
