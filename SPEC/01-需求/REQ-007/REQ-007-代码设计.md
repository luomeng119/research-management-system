## 2 数据库 Schema

### 2.1 表总览

| 表名 | 说明 |
|------|------|
| `generic_tables` | 表格元数据（名称、创建人等） |
| `generic_table_versions` | 版本记录（每版本的快照元信息） |
| `generic_table_columns` | 列定义（每个版本的列结构） |
| `generic_table_data` | 行数据（每行 JSON 存所有列值） |

### 2.2 建表 SQL

```sql
-- 表格元数据
CREATE TABLE IF NOT EXISTS generic_tables (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    table_id TEXT UNIQUE NOT NULL,          -- 业务ID，如 GT20250712103000
    name TEXT NOT NULL,                     -- 表格名称
    description TEXT,                       -- 描述
    creator TEXT NOT NULL,                  -- 创建人
    created_at TEXT NOT NULL,               -- 创建时间
    updated_at TEXT NOT NULL                -- 更新时间
);

-- 版本记录
CREATE TABLE IF NOT EXISTS generic_table_versions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    version_id TEXT UNIQUE NOT NULL,        -- 版本ID，如 GTV20250712103001
    table_id TEXT NOT NULL,                 -- 所属表格
    version_number INTEGER NOT NULL,         -- 版本号（整数，递增）
    version_label TEXT,                      -- 版本标签（如"正式版v1"）
    create_method TEXT NOT NULL,             -- 'snapshot' | 'import'
    source_version_id TEXT,                  -- 来源版本ID（snapshot/import时）
    row_count INTEGER DEFAULT 0,             -- 行数（冗余，便于列表展示）
    creator TEXT NOT NULL,                  -- 操作人
    created_at TEXT NOT NULL,               -- 创建时间
    note TEXT,                              -- 版本说明
    FOREIGN KEY (table_id) REFERENCES generic_tables(table_id),
    FOREIGN KEY (source_version_id) REFERENCES generic_table_versions(version_id)
);

-- 列定义（每个版本的列结构，独立维护）
CREATE TABLE IF NOT EXISTS generic_table_columns (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    version_id TEXT NOT NULL,               -- 所属版本
    col_key TEXT NOT NULL,                  -- 列标识（英文字段名）
    col_name TEXT NOT NULL,                  -- 列显示名
    col_type TEXT NOT NULL,                  -- 类型：text | number | date | select
    col_index INTEGER NOT NULL,              -- 列顺序
    col_width INTEGER DEFAULT 120,          -- 列宽（px）
    col_align TEXT DEFAULT 'left',           -- 对齐：left | center | right
    col_summary TEXT,                        -- 汇总类型：'' | 'count' | 'sum' | 'avg'
    col_options TEXT,                        -- select选项，JSON数组
    created_at TEXT NOT NULL,
    FOREIGN KEY (version_id) REFERENCES generic_table_versions(version_id),
    UNIQUE(version_id, col_key)
);

-- 行数据（每行存为一行，列值为JSON）
CREATE TABLE IF NOT EXISTS generic_table_data (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    version_id TEXT NOT NULL,               -- 所属版本
    row_key TEXT NOT NULL,                    -- 行唯一标识（UUID）
    row_index INTEGER NOT NULL,               -- 行顺序
    row_data TEXT NOT NULL,                   -- JSON：{col_key: value, ...}
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    FOREIGN KEY (version_id) REFERENCES generic_table_versions(version_id),
    UNIQUE(version_id, row_key)
);

-- 索引（查询优化）
CREATE INDEX IF NOT EXISTS idx_gv_table_id ON generic_table_versions(table_id);
CREATE INDEX IF NOT EXISTS idx_gc_version_id ON generic_table_columns(version_id);
CREATE INDEX IF NOT EXISTS idx_gd_version_id ON generic_table_data(version_id);
```

## 3 模型类设计

### 3.1 GenericTableModel

```python
class GenericTableModel:
    # 表级CRUD
    def get_all()                           # 返回所有表格（带最新版本信息）
    def get_by_id(table_id)                 # 返回单表元数据
    def create(name, description, creator)  # 创建新表格，自动创建v1版本空结构
    def update(table_id, **kwargs)          # 更新表格元数据

    # 版本管理
    def create_version(table_id, method, source_version_id, creator, label, note)
        # method='snapshot': 完整复制源版本的数据和列结构
        # method='import':    从上传Excel解析列结构和数据（自动存档旧版）
    def get_versions(table_id)              # 返回表格的所有版本（按version_number DESC）
    def get_version_by_id(version_id)       # 返回单版本元数据
    def delete_version(version_id)          # 删除版本（同时删列定义+行数据）

    # 列管理
    def get_columns(version_id)              # 返回某版本的列定义列表（按col_index排序）
    def upsert_column(version_id, col_key, col_name, col_type, ...)  # 新增或更新列
    def delete_column(version_id, col_key)  # 删除列（同时删该列在所有行中的值）
    def reorder_columns(version_id, col_keys)  # 批量重排列顺序

    # 行数据
    def get_rows(version_id)                 # 返回行数据列表（解析JSON）
    def upsert_row(version_id, row_key, row_data_dict)  # 插入或更新行
    def delete_row(version_id, row_key)     # 删除行
    def import_rows_from_excel(version_id, file_path)   # 从Excel批量导入

    # 搜索与统计
    def search_rows(version_id, keyword)     # 快速搜索（所有列模糊匹配）
    def get_column_stats(version_id)          # 返回每列的汇总统计
    def compare_versions(version_id_a, version_id_b)     # 返回两版本差异（行级别）
```

## 8 关键技术决策

### 8.1 数据存储方案
- **行数据**：所有列值存为一行 JSON（`row_data` TEXT），避免列变更时需 ALTER TABLE
- **列定义独立表**：每列的定义信息存在 `generic_table_columns`，支持每个版本独立维护列结构
- **汇总统计**：按需计算，不冗余存储（`stats` 接口实时计算）

### 8.2 版本创建
- **snapshot 方式**：INSERT SELECT 复制所有行数据 + 列定义，O(n) 数据拷贝
- **import 方式**：解析 Excel → 提取列结构 → 批量导入数据，自动将当前版本变为"存档版"

### 8.3 版本对比算法
- 以 `all_columns`（两版本列的并集）为基准
- 行匹配：以 `row_key`（UUID）为准
- 状态判定：双方都有 → modified/unchanged；仅A有 → deleted；仅B有 → added

### 8.4 搜索实现
- 搜索参数 `q` 传递到后端，在 Python 层遍历行数据 JSON 做 LIKE 模糊匹配
- 当前版本数据量预估 < 10万行，Python 遍历可接受；后续如需优化可加 SQLite FTS5

### 8.5 Excel 导入
- 使用 `openpyxl` 读取 `.xlsx` 文件
- 第一行自动识别为列定义（字段名）
- 数据从第二行开始
- 编码统一用 UTF-8（xlsx 本身是 UTF-8）
