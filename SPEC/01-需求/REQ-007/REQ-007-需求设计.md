## 一、用户描述整理复述

**用户原始描述：**
> 工作中需要处理、维护多种类型的 Excel 表格文件，涉及设备编配使用。目前存在多种功能表，每种功能表的结构都不一样，希望通过系统实现数据的维护、统计、管理、更新。支持自定义表格的导入、导出，多版本数据对比等。

**整理复述（AI）：**
用户需要在科研管理系统中新增一个**通用表格管理模块**，用于：
- 将各种独立业务的自定义 Excel 表格（设备台账、人员清单等）导入系统进行管理
- 同一业务支持多版本，每个版本有独立的列结构和数据，可创建快照、可存档旧版本
- 支持在线查看、编辑、筛选、统计当前版本数据
- 支持两个版本之间的数据对比，高亮显示差异
- 支持导出为标准 Excel 文件
- 表格列结构支持动态调整（每版本独立）

如上理解与您的实际需求一致，请确认。如有偏差请指出。

## 二、功能理解

### 核心要解决的问题
1. **散落各处的 Excel 文件无法统一管理**：版本混乱、格式不统一、难以追溯变更
2. **多版本对比靠人工**：手工对比两个 Excel 文件费时且容易出错
3. **缺乏版本控制**：不知道哪个是最新、哪个是正式版本
4. **筛选统计困难**：Excel 的筛选统计功能有限，不够灵活

### 核心功能模块

| 模块 | 功能说明 |
|------|---------|
| **表格管理** | 创建、删除、导入、导出表格；每表格独立管理 |
| **版本管理** | 每表格下多个版本；创建快照、导入覆盖（存档旧版） |
| **数据编辑** | 在线查看/编辑当前版本的行数据 |
| **结构管理** | 动态调整当前版本的列（增删改列名/类型） |
| **筛选统计** | 对当前版本数据进行条件筛选、汇总统计 |
| **版本对比** | 任意两个版本之间对比，高亮差异行/列 |

## 三、子需求分析

### 子需求拆解

#### S-1：表格的增删改查
- 创建新表格：输入表格名称，选择是否导入初始 Excel
- 删除表格：确认后删除，包括所有版本
- 表格列表：显示所有表格名称、当前版本数、更新时间

#### S-2：版本的增删管理
- **创建快照**：基于当前版本复制一份，生成新版本号（如 v2 ← v1 复制）
- **导入新版本**：上传 Excel → 存档当前版本为 v(N-1) → 导入为新 vN
- **版本列表**：显示每表格下所有版本（版本号、创建时间、备注、当前标识）
- **删除旧版本**：可删除指定版本（保留至少1个）
- **切换当前版本**：将某历史版本设为当前活动版本

#### S-3：列结构管理（每版本独立）
- 查看当前版本的列清单（列名、数据类型、是否必填）
- 添加列：输入列名、选择数据类型（文本/数字/日期/下拉选择）
- 删除列：该列下所有数据同步删除，需二次确认
- 修改列：列名、数据类型
- **注意**：修改列结构不影响同表格下其他版本

#### S-4：行数据管理（每版本独立）
- 列表展示：分页展示数据行，支持排序
- 添加行：在线填写各列数据
- 编辑行：点击行内数据直接编辑，保存
- 删除行：勾选后批量删除
- **注意**：数据编辑只作用于当前活动版本

#### S-5：筛选与统计
- 筛选器：各列可设置筛选条件（等于/包含/大于/小于/区间）
- 统计栏：显示当前筛选结果的总行数，以及数值列的总和/平均值
- 重置：清除所有筛选条件

#### S-6：Excel 导入
- 上传 .xlsx / .xls 文件
- 自动识别第一行作为列标题（列名）
- 自动识别数据类型（文本/数字/日期）
- 用户确认列映射后可导入
- 导入后自动创建新版本

#### S-7：Excel 导出
- 导出当前版本全部数据为 .xlsx
- 导出当前筛选结果为 .xlsx
- 保留列结构和表头

#### S-8：版本对比
- 选择同一表格下的任意两个版本进行对比
- 以并排表格形式展示（左侧版本A，右侧版本B）
- 高亮显示：新增行（绿色）、删除行（红色）、修改行（黄色）
- 支持导出对比结果为 Excel

## 五、流程分析

### 5.1 表格创建流程
```
用户点击"新建表格"
        ↓
输入表格名称（必填）
        ↓
[可选] 上传初始 Excel 文件
        ↓
系统解析 Excel → 生成 v1 版本
        ↓
表格创建完成，进入表格详情页
```

### 5.2 版本管理流程
```
用户进入某表格详情页（当前版本）
        ↓
点击"新版本"按钮
        ├─ 选择"上传Excel" → 存档当前版本 → 解析上传文件 → 生成新版本
        └─ 选择"创建快照" → 复制当前版本 → 生成新版本
        ↓
新版本成为当前活动版本
```

### 5.3 数据编辑流程
```
用户在表格详情页浏览数据
        ↓
点击"添加行"/点击单元格编辑
        ↓
修改数据后点击保存
        ↓
数据更新，仅影响当前版本
```

### 5.4 筛选统计流程
```
用户在表格详情页设置筛选条件
        ↓
列表实时刷新，显示符合条件的数据
        ↓
底部统计栏显示：总行数、关键数值列汇总
        ↓
用户可导出当前筛选结果为 Excel
```

### 5.5 版本对比流程
```
用户点击"版本对比"
        ↓
选择两个版本（版本A vs 版本B）
        ↓
系统计算差异（行级别 + 列级别）
        ↓
并排展示，高亮差异
        ↓
可导出对比结果
```

## 六、场景分析

### 正常场景
1. 用户导入一个设备台账 Excel，系统自动建表并生成 v1
2. 用户编辑台账中某设备的使用人信息，保存
3. 用户导入新版台账 Excel，系统存档旧版，自动创建 v2
4. 用户对 v2 筛选"状态=在用"，统计总数量
5. 用户对比 v1 和 v2，查看新增了哪些设备

### 边界/异常场景
1. **空表格**：没有任何数据时，显示"暂无数据，请导入 Excel 或添加行"
2. **列结构变更后**：旧版本有某列，新版本删除了该列 → 对比时该列显示为空
3. **导入 Excel 列数少于现有版本**：多余的列保留，数据为空
4. **导入 Excel 列数多于现有版本**：自动新增列，数据为空
5. **删除最后一列**：不允许，应至少保留1列
6. **删除表格**：需用户二次确认，提示"将删除所有版本数据"
7. **大文件导入**：Excel 超过 1000 行时，显示导入进度条

## 七、数据模型初稿

### 实体设计

| 实体 | 说明 |
|------|------|
| `TableMeta` | 表格元数据（ID、名称、创建时间） |
| `TableVersion` | 版本（ID、表格ID、版本号、创建时间、是否当前） |
| `VersionColumn` | 列定义（ID、版本ID、列名、列顺序、数据类型、是否必填） |
| `VersionRow` | 行数据（ID、版本ID、列ID、单元格值） |
| `TableSnapshot` | 快照（ID、版本ID、快照名称、创建时间） |

### 数据流转示意
```
TableMeta (1) ─── (N) TableVersion (1) ─── (N) VersionColumn
                    │
                    └── (N) VersionRow
```
