---

## 页面结构

本模块包含 **4个页面**：

1. **表格列表页** `/tables` — 所有表格的汇总展示
2. **表格详情页** `/tables/<tid>` — 当前版本的数据查看/编辑/筛选
3. **列管理面板**（侧边抽屉） — 当前版本的列结构配置
4. **版本管理弹窗** — 版本的增删切操作
5. **版本对比页** `/tables/<tid>/compare` — 两版本并排对比

### 交互说明

| 元素 | 行为 |
|------|------|
| `[版本：v3 ▼]` | 下拉切换当前活动版本（切换后刷新数据） |
| `[+添加行]` | 在列表底部插入一行空白数据，行内编辑 |
| `[列管理]` | 右侧滑出抽屉面板，管理当前版本列结构 |
| `[导入Excel]` | 上传 .xlsx，覆盖当前版本（自动存档旧版） |
| `[导出Excel]` | 导出当前版本全部数据或筛选结果为 .xlsx |
| `[删除所选]` | 批量删除勾选的行，需二次确认 |
| 单元格点击 | 行内编辑，Enter 保存，Esc 取消 |
| 筛选器 | 下拉选择列→条件→值，实时刷新列表 |
| 合计行 | 筛选后显示匹配行数 + 数值列自动求和 |

## 页面四：版本对比页 `/tables/<tid>/compare`

### 布局图（ASCII）

```
┌──────────────────────────────────────────────────────────────────────┐
│  ◀ 返回详情        设备台账 - 版本对比                               │
├──────────────────────────────────────────────────────────────────────┤
│  对比版本： [v1 ▼]  对比  [v3 ▼]          [▶ 开始对比]  [导出对比结果] │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  ┌─────────────────────────┐   ┌─────────────────────────┐          │
│  │ v1（基准版本）          │   │ v3（对比版本）          │          │
│  │ 2026-02-01             │   │ 2026-04-15             │          │
│  ├─────────────────────────┤   ├─────────────────────────┤          │
│  │ 行2 ★ 修改（黄色）     │   │ 行2 ★ 修改（黄色）     │          │
│  │ 行3 ★ 新增（绿色）     │   │ 行3 ★ 新增（绿色）     │          │
│  │ 行5 ★ 删除（红色）     │   │ 行5 ────────────────   │          │
│  └─────────────────────────┘   └─────────────────────────┘          │
│                                                                      │
│  图例：  🟩 新增行   🟨 修改行   🟥 删除行   ─ 不存在               │
└──────────────────────────────────────────────────────────────────────┘
```

### 差异说明
- **绿色高亮**：该行在对版本中存在，在基准版本中不存在（新增）
- **黄色高亮**：该行在两版本中都存在，但有单元格值不同
- **红色高亮**：该行在基准版本中存在，在对版本中不存在（删除）
- **对齐逻辑**：按第一唯一列（如序号/ID）自动对齐，无唯一列时按行号
