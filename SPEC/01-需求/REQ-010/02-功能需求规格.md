# REQ-010 研制单位字典功能 — 功能需求规格

## 一、数据模型

### 1.1 数据库表：research_units

```sql
CREATE TABLE research_units (
    unit_id   TEXT PRIMARY KEY,           -- 主键，如 'RU001'
    unit_name TEXT NOT NULL UNIQUE,       -- 单位名称，如 '数据所'
    created_at TEXT NOT NULL,             -- 创建时间
    updated_at TEXT NOT NULL              -- 更新时间
);
```

- `unit_id` 格式：`RU` + 3位序号（如 RU001, RU002...）
- 软删除：不设删除标志，删除前校验引用，有引用则拒绝删除

### 1.2 关联关系

设备知识库表 `equipment` 字段 `manufacturer` 存储多选单位名称，以 `、`分隔（与原有单字符串格式兼容）。

## 二、字典管理 UI

### 2.1 入口

挂在设备知识库列表页（`/equipment/`）顶部工具栏右侧，按钮文字："研制单位管理"。

### 2.2 模态框布局

```
┌──────────────────────────────────────────┐
│ 研制单位管理                         [X] │
├──────────────────────────────────────────┤
│ [+ 新增单位]                             │
├──────────────────────────────────────────┤
│ 序号 │ 单位名称        │ 操作            │
│ RU001│ 数据所          │ [编辑] [删除]   │
│ RU002│ 30所            │ [编辑] [删除]   │
│ ...  │ ...             │ ...             │
└──────────────────────────────────────────┘
```

### 2.3 新增/编辑表单

模态框内嵌表单：
- 单位名称（文本框，必填，唯一性校验）

### 2.4 删除校验

点击删除时：
- 调用 API 检查 `equipment` 表中 `manufacturer` 字段包含该单位名的记录数
- 若 count > 0：提示"该单位被 N 台设备引用，不可删除"
- 若 count == 0：确认后删除

## 三、设备表单改造

### 3.1 设备知识库表单

新增/编辑设备页面（`/equipment/add`，`/equipment/edit/<id>`）：
- "研制单位"字段从 `<input type="text">` 改为 `<select multiple>`
- Bootstrap Multi-Select 样式美化
- 必填性保持不变

### 3.2 多选数据存储格式

`manufacturer` 字段存储为分隔字符串：`"数据所、30所、722所"`

### 3.3 列表页展示

设备知识库列表页 `manufacturer` 列直接显示字符串（不解析多选，原样展示）。

## 四、权限控制

- 字典管理入口：仅 `session.get('is_admin') == True` 时显示
- API 层面：`/api/research-units/*` 所有操作均校验管理员身份
