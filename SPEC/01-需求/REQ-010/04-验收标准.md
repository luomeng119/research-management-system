# REQ-010 研制单位字典功能 — 验收标准

## 一、数据模型验收

- [ ] `research_units` 表创建成功，字段正确
- [ ] `unit_id` 格式为 `RU` + 3位序号，自动递增
- [ ] 初始7条数据插入成功

## 二、字典管理 UI 验收

- [ ] 管理员登录后，设备知识库列表页顶部显示"研制单位管理"按钮
- [ ] 非管理员登录后，不显示该按钮
- [ ] 点击按钮弹出模态框，显示单位列表
- [ ] 新增单位：输入名称 → 保存成功 → 列表刷新显示
- [ ] 编辑单位：点击编辑 → 修改名称 → 保存成功 → 列表刷新
- [ ] 删除未引用单位：点击删除 → 确认 → 删除成功 → 列表刷新
- [ ] 删除已被设备引用的单位：提示"该单位被 N 台设备引用，不可删除"

## 三、设备表单验收

- [ ] 新增设备页面，"研制单位"字段为多选下拉框
- [ ] 下拉框列出字典表所有单位
- [ ] 可选择多个单位
- [ ] 保存后，`manufacturer` 字段正确存储多选值（如"数据所、30所"）
- [ ] 编辑已有设备时，已选中的研制单位正确回显

## 四、权限验收

- [ ] 非管理员用户无法通过 URL 直接访问 `/api/research-units/*`
- [ ] 非管理员用户无法通过浏览器直接操作字典

## 五、回归验收

- [ ] 设备知识库列表页正常显示
- [ ] 设备详情页正常显示
- [ ] 设备新增/编辑其他字段不受影响
- [ ] 宿主设备库功能不受影响
