# REQ-010 研制单位字典功能

## 1. 用户需求描述

设备知识库的"研制单位"字段目前为自由文本输入方式，导致数据不规范（同一单位可能有多种写法，如"数据所"、"数据研究院"等）。需要建立研制单位字典表进行统一管理。

## 2. 功能理解

- 研制单位是设备知识库的字段之一，录入/编辑设备时需要填写
- 通过字典表规范可选值，录入时从下拉框选择（支持多选）
- 字典表由管理员维护（新增/编辑/删除单位名称）
- 删除单位时检查是否有设备引用该单位，有则拒绝删除

## 5. 流程

### 字典维护流程（管理员）
1. 管理员访问设备知识库列表页
2. 页面顶部工具栏显示"研制单位管理"按钮
3. 点击弹出模态框，显示单位列表
4. 可新增单位名称、编辑已有单位、删除未引用单位
5. 删除时若有设备引用，提示不可删除并列出引用设备数量

### 设备录入流程（普通用户）
1. 新增或编辑设备
2. "研制单位"字段显示为多选下拉框
3. 从下拉框中选择一个或多个单位
4. 保存后，设备与选中的研制单位关联

## 6. 场景

- **场景A**：管理员新增"数据所"到字典表 → 设备工程师录入设备时可选择"数据所"
- **场景B**："数据所"已被5台设备引用 → 管理员删除"数据所"时提示"该单位被5台设备引用，不可删除"
- **场景C**：管理员编辑"30所"为"三十所" → 所有引用"30所"的设备自动更新显示为"三十所"
