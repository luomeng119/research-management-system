## 交互流程汇总

| 操作 | 触发 | API 调用 | 成功响应 |
|------|------|---------|---------|
| 新增单位 | 点击[保存] | POST /api/research-units | 刷新列表 |
| 编辑单位 | 点击[保存] | PUT /api/research-units/<id> | 行更新为新名称 |
| 删除单位 | 点击[确认删除] | DELETE /api/research-units/<id> | 行从列表移除 |
| 删除校验 | 点击[删除] | GET /api/research-units/<id>/ref-count | 有引用则阻止 |

---

## 字段冲突处理

| 场景 | 处理 |
|------|------|
| 新增单位名称为空 | 前端拦截，提示"单位名称不能为空" |
| 新增单位名称已存在 | 提示"该单位已存在"，不提交 |
| 编辑后名称与已有重复 | 提示"该单位已存在"，不保存 |
| 删除被引用的单位 | 显示引用设备列表，删除按钮禁用 |
