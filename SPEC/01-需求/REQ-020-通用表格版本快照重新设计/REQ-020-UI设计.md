# REQ-020 UI 设计

## 1. 设计原则

- **彻底分离**"当前编辑版本"和"历史快照"的视觉表现
  - 当前编辑版本：绿色标识 + 可编辑控件 + 显眼位置
  - 历史快照：灰色标识 + 只读标识 + 折叠/侧栏次要位置
- **业务优先**：用户进入详情页默认看到 current_version，不需要"先选版本"
- **最小改动**：保留现有 detail.html 布局（顶部工具栏 + 主内容区），只在右侧新增版本侧边栏 + 调整工具栏文案
- **快照明确化**：去掉"快照"作为顶部按钮的混淆位置，改为侧边栏里的"保存快照"按钮

## 3. 顶部工具栏（重新设计）

### 3.1 现有布局（REQ-019 后）

```
[← 返回] | 表格名 [版本下拉] [🔒快照锁定] [📷快照] [列管理] [📥导入] [📤导出]
```

### 3.2 新布局

```
[← 返回] | 表格名 [版本下拉] [🟢当前编辑] [📷保存快照] [列管理] [📥导入] [📤导出] [🔀对比]
```

#### 3.2.1 版本下拉（变化）

- **位置**：表格名右侧
- **行为**：下拉里只列历史快照（v2、v3 等），**不列 current**
- 默认显示 "当前编辑版本 (v3)"，不展开
- 展开后：列出所有历史快照（label + 创建人 + 创建时间）
- 选某个历史快照 → 跳到 `/generic-tables/<table_id>/version/<vid>/`（**只读模式**）
- **不**通过下拉选 current（current 永远是默认页）

#### 3.2.2 锁定徽章（变化）

- **当前**：REQ-019 的金色徽章 "🔒 快照锁定 - 不可修改行数据"（is_locked=1 时显示）
- **新设计**：
  - is_locked=0：显示**绿色**徽章 "🟢 当前编辑"（**永远显示**）
  - is_locked=1：显示**金色**徽章 "🔒 只读快照"（**只在历史快照详情页显示**）
- 徽章位置在版本下拉右侧

#### 3.2.3 保存快照按钮（变化）

- **当前**：📷 "快照" 按钮，触发 `createSnapshot()`
- **新设计**：
  - **从顶部工具栏移到右侧版本侧边栏**（主区域不需要"先建快照"概念）
  - 顶部保留一个"快速保存"按钮 📷，点击直接弹窗输入 label/note

#### 3.2.4 导入按钮（行为变化）

- **当前**：点击 → 先建 snapshot → 导入到 snapshot
- **新设计**：点击 → 直接弹文件选择 → 导入到 current
- 视觉不变（白底绿字 + 向上箭头图标）

#### 3.2.5 对比按钮（新增）

- **位置**：导出按钮右侧
- **图标**：🔀 双向箭头
- **行为**：点击弹窗选历史快照，显示 current vs 选中快照的差异
- 复用现有 compare.html 模板，但默认 current 为基准

## 4. 右侧版本侧边栏（新增）

### 4.1 当前编辑版本卡片

```
┌────────────────────────────────────┐
│ 🟢 当前编辑版本                      │
│                                    │
│ v3  50行 / 8列                       │
│ 创建于 2026-06-28 14:32             │
│ 创建人 admin                         │
│                                    │
│ ┌──────────────────────────────┐   │
│ │   📷 保存快照                 │   │
│ └──────────────────────────────┘   │
└────────────────────────────────────┘
```

- **位置**：侧边栏顶部
- **背景**：浅绿色（#f0fdf4 渐变到 #dcfce7）
- **边框**：绿色 2px solid #16a34a
- **状态**：永远显示，**每个表格只有一个**
- **保存快照按钮**：满宽，主操作
  - 点击 → 弹窗（见 §5.1）
  - 后端成功后 → 刷新页面，自动跳到新的 current

### 4.2 历史快照列表

```
历史快照（3）

┌────────────────────────────────────┐
│ 📷 v2 导入前存档                       │
│ 2026-06-28 14:30  admin 创建          │
│                         [↩ 回滚到此]   │
├────────────────────────────────────┤
│ 📷 v1 初始版本                        │
│ 2026-06-27 10:15  admin 创建          │
│                         [↩ 回滚到此]   │
└────────────────────────────────────┘
```

- **位置**：当前编辑版本卡片下方
- **标题**："历史快照（N）"，N = 数量
- **每行内容**：
  - 图标 📷 + label（如 v2 导入前存档，没有 label 则显示 v2 2026-06-28 14:30）
  - 创建时间 + 创建人
  - "回滚到此" 按钮（次要按钮，文字链样式）
- **样式**：白底，浅灰边框，每行 hover 高亮
- **回滚按钮行为**：
  - 点击 → 弹窗（见 §5.2）
  - 确认后 → 后端创建新 current → 刷新页面

### 4.3 滚动与折叠

- **滚动**：历史快照 > 10 条时侧边栏内部滚动
- **空状态**：没有历史快照时显示"暂无历史快照，点击保存快照按钮创建"

## 5. 弹窗

### 5.1 保存快照弹窗

```
┌────────────────────────────────────┐
│  保存当前版本为快照                  │
│                                    │
│  快照名称：[输入框______________]   │
│                                    │
│  快照说明（选填）：                  │
│  [多行输入框________________]        │
│  [_____________________________]    │
│  [_____________________________]    │
│                                    │
│            [取消]   [确认保存]      │
└────────────────────────────────────┘
```

- 名称必填，最长 50 字
- 说明选填，最长 500 字
- 取消/确认按钮：取消（灰底）/ 确认保存（绿底）
- 确认后：
  - 后端：复制 current 为新 snapshot (is_locked=1) + 创建新 current (is_locked=0) + 更新 current_version_id
  - 前端：刷新整个页面，URL 不变（仍为 `/generic-tables/<table_id>/`）
  - 侧边栏新快照出现在历史快照列表顶部

### 5.2 回滚确认弹窗

```
┌────────────────────────────────────┐
│  回滚到历史快照 v2                    │
│                                    │
│  源版本：v2  导入前存档                │
│  创建于：2026-06-28 14:30            │
│                                    │
│  ⚠ 警告：                            │
│  回滚将基于 v2 创建新的编辑版本 v4，   │
│  v3（当前编辑版本）将成为历史快照。     │
│  v2、v3 数据都不会丢失。              │
│                                    │
│            [取消]   [确认回滚]      │
└────────────────────────────────────┘
```

- 警告文案明确说明"不会丢失数据"
- 取消（灰底）/ 确认回滚（黄底）
- 确认后：
  - 后端：从 source 复制为新 current (method='rollback', is_locked=0) + 更新 current_version_id
  - 前端：刷新页面，跳到新 current
  - 侧边栏：原 current 变成历史快照，新 current 出现在顶部

### 5.3 对比弹窗

```
┌────────────────────────────────────┐
│  对比历史快照                        │
│                                    │
│  选择要对比的快照：                    │
│  [v2 导入前存档        ▼]           │
│                                    │
│            [取消]   [开始对比]      │
└────────────────────────────────────┘
```

- 复用现有 compare.html 模板
- 取消（灰底）/ 开始对比（蓝底）
- 确认后跳到 `/generic-tables/<table_id>/compare/<v2_id>/`

## 6. 历史快照只读详情页

### 6.1 路由

- `/generic-tables/<table_id>/` → 默认 current（可编辑）
- `/generic-tables/<table_id>/version/<vid>/` → 指定版本（**只读**）

### 6.2 视觉差异

- 顶部徽章变 "🔒 只读快照"（金色）
- 工具栏的"保存快照" / "导入" / "列管理" / "对比" 按钮**全部置灰或隐藏**
- 侧边栏的"保存快照"按钮**隐藏**
- 行操作（添加/删除/编辑单元格）**全部禁用**
- 改色和列宽调整（REQ-019 不锁的）**也禁用**（历史快照完全只读）

## 7. 列表页（list.html）

### 7.1 变化

- 不变（列表页只展示表格基本信息，不需要"current"概念）
- 但**新增**一列"当前编辑版本"显示：`v3 (admin · 2026-06-28 14:32)`
- 列表数据查询 SQL 加 `LEFT JOIN generic_table_versions ON current_version_id`

```
┌──────────────────────────────────────────────────────────────┐
│  通用表格                              [+ 新建表格]              │
│                                                              │
│  名称        │ 当前版本 │ 创建人 │ 更新时间   │ 状态 │ 操作    │
│ ────────────────────────────────────────────────────────────│
│  设备列表    │ v3 admin  │ 张三  │ 2026-06-28 │ 正常 │ 详情... │
│  专家列表    │ v1 admin  │ 李四  │ 2026-06-27 │ 正常 │ 详情... │
│  ...                                                        │
└──────────────────────────────────────────────────────────────┘
```

## 8. 颜色与图标规范

### 8.1 颜色

- 当前编辑：#16a34a（绿）—— 徽章、卡片边框、按钮
- 只读快照：#f59e0b（金）—— 徽章、警示
- 普通按钮：#0d6efd（蓝）—— 链接、对比
- 危险按钮：#dc3545（红）—— 删除（**不涉及本次**，不出现）

### 8.2 图标

- 🟢 当前编辑（用 Bootstrap 圆形填充图标 bi-circle-fill）
- 📷 快照（用 bi-camera）
- ↩ 回滚（用 bi-arrow-counterclockwise）
- 🔀 对比（用 bi-arrow-left-right）
- 🔒 锁定（用 bi-lock-fill，REQ-019 已有）
- 📥 导入（用 bi-upload，REQ-019 已有）
- 📤 导出（用 bi-download，REQ-019 已有）

## 9. 错误提示样式

- 顶部工具栏下方一行 Bootstrap Alert
- 错误：红底白字（#dc3545 背景 + 白字）
- 警告：黄底深灰字（#ffc107 背景 + #333 字）
- 成功：绿底白字（#16a34a 背景 + 白字）
- 自动消失：成功 3 秒后渐隐，错误不自动消失

## 10. 响应式

- 桌面（≥1280px）：主内容 + 右侧 300px 侧边栏，完整布局
- 平板（992~1279px）：侧边栏缩到 240px，文字缩短
- 窄屏（768~991px）：侧边栏移到主内容下方（上下布局），变成可折叠面板
- 手机（<768px）：本期不专门适配

## 11. 不在 UI 设计范围

- 暗色模式（保持当前浅色）
- 多语言（保持中文）
- 协作编辑指示（本期没有协同）
- 通知/邮件提醒（保存快照不发通知）
- 移动端原生体验
- 版本树视图（本期是线性列表）
