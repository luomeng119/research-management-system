# REQ-017 UI 设计

## 1. 设计原则

- 复用设备导入的视觉语言（顶部步骤指示器 + 中部内容区 + 底部固定按钮栏）
- 简化版式：专家导入无"分类选择""智能匹配"等复杂交互，每步页面元素 < 10 个
- 颜色规范：复用设备导入的颜色（绿色=确认、黄色=警告、红色=跳过、灰色=辅助）

## 2. 整体布局

```
┌──────────────────────────────────────────────────────────────┐
│  顶部导航（系统全局，不变）                                       │
├──────────────────────────────────────────────────────────────┤
│  页面标题：批量导入专家信息                                        │
│  步骤指示器：● ① 上传  ─ ② 预览  ─ ③ 结果                        │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│              [步骤 1/2/3 的内容区，根据路由切换]                  │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│  底部固定按钮栏（左侧返回 / 右侧下一步或确认）                       │
└──────────────────────────────────────────────────────────────┘
```

## 3. 步骤 1：上传 + 列映射

### 3.1 顶部：上传区

```
┌──────────────────────────────────────────────────────────────┐
│  ┌──────────────────────────────────────────────────────┐    │
│  │                                                      │    │
│  │           拖拽 .xlsx 文件到此处                       │    │
│  │           或 [点击选择文件]                            │    │
│  │                                                      │    │
│  │           支持 .xlsx 格式，单次最多 1000 条            │    │
│  └──────────────────────────────────────────────────────┘    │
│                                                              │
│  已选择：批量导入名册.xlsx（156 KB，87 行数据）                   │
└──────────────────────────────────────────────────────────────┘
```

未上传时：上传区虚线边框 + 灰色"拖拽或点击"提示
已上传时：上传区显示文件名 + 大小 + 行数，右侧"重新选择"按钮

### 3.2 中部：Excel 前 10 行预览表

```
┌──────────────────────────────────────────────────────────────┐
│  Excel 内容预览（前 10 行）                                     │
│  ┌────────┬────────┬────────┬────────┬────────┐              │
│  │ 姓名   │ 单位   │ 职务   │ 电话   │ 身份证号 │              │
│  ├────────┼────────┼────────┼────────┼────────┤              │
│  │ 张三   │ 30所   │ 高工   │ 138... │ 110...  │              │
│  │ 李四   │ 电子6所 │ 研究员 │ 139... │ 110...  │              │
│  │ ...    │ ...    │ ...    │ ...    │ ...     │              │
│  └────────┴────────┴────────┴────────┴────────┘              │
│  共 87 行（仅显示前 10 行）                                     │
└──────────────────────────────────────────────────────────────┘
```

样式：表格紧凑、字号 13px、列宽自适应、不允许水平滚动（Excel 列多时按比例缩）

### 3.3 下部：列映射下拉

```
┌──────────────────────────────────────────────────────────────┐
│  列映射（把 Excel 列对应到专家字段）                                │
│                                                              │
│  Excel 列：姓名    →  映射到：[姓名 ▼]                            │
│  Excel 列：单位    →  映射到：[单位 ▼]                            │
│  Excel 列：职务    →  映射到：[职务 ▼]                            │
│  Excel 列：电话    →  映射到：[电话 ▼]                            │
│  Excel 列：身份证号 →  映射到：[身份证号 ▼]                        │
│  Excel 列：备注    →  映射到：[忽略此列 ▼]                        │
│                                                              │
│  [智能预选]  [清空映射]                                          │
│                                                              │
│  校验：● 姓名列已映射  ● 其他字段选填                             │
└──────────────────────────────────────────────────────────────┘
```

下拉选项（每个下拉都包含）：
- 姓名 / 单位 / 职务 / 专长 / 电话 / 身份证号 / 银行卡号 / 开户行 / 上传人
- 忽略此列

校验提示：
- 姓名列未映射 → "下一步"按钮置灰 + 红字提示"姓名列未映射，无法继续"
- 数据行 > 1000 → "下一步"按钮置灰 + 红字提示"超出 1000 条上限，请拆分"
- 文件 > 20MB → 上传时直接拒绝，提示"文件过大（>20MB）"

### 3.4 底部按钮栏

```
┌──────────────────────────────────────────────────────────────┐
│  [返回列表]                                  [下一步 →]          │
└──────────────────────────────────────────────────────────────┘
```

左下："返回列表"（灰底）—— 跳 /experts/
右下："下一步"（蓝底）—— 跳 /experts/import/preview，未满足校验时置灰

## 4. 步骤 2：逐行预览确认

### 4.1 顶部：统计与批量操作

```
┌──────────────────────────────────────────────────────────────┐
│  共 87 行：✓ 84 待确认  ⊘ 3 跳过（缺姓名）                        │
│                                                              │
│  [全选]  [反选]  [展开所有修改]                                    │
└──────────────────────────────────────────────────────────────┘
```

颜色规范：
- 绿色 ✓：待确认（默认）
- 红色 ⊘：跳过（缺姓名，不可改）
- 蓝色：当前正在编辑的行

### 4.2 中部：逐行预览表

```
┌──────────────────────────────────────────────────────────────┐
│  # │ 状态    │ 姓名 │ 单位 │ 职务 │ 电话 │ 身份证号 │ 操作         │
│ ─────────────────────────────────────────────────────────────│
│  1 │ ✓ 待确认 │ 张三 │ 30所 │ 高工 │ 138...│ 110... │ [修改][跳过] │
│  2 │ ✓ 待确认 │ 李四 │ 电子6所│研究员 │ 139...│ 110... │ [修改][跳过] │
│  3 │ ⊘ 跳过   │ --   │ --   │ --   │ --    │ --     │ [查看]      │
│  ...                                                            │
└──────────────────────────────────────────────────────────────┘
```

每行布局：
- #：行号（1-based，从 Excel 第 2 行起算）
- 状态：图标 + 文字
- 字段列：name / unit / position / phone / id_card（按用户列映射选中的字段动态显示列名）
- 操作：[修改]（弹出/展开行内编辑） / [跳过]（手动标跳过） / [查看]（仅可看，不可改）

行内修改展开后：

```
┌──────────────────────────────────────────────────────────────┐
│  3 │ ✓ 待确认 │ 张三 │ 30所 │ 高工 │ 138... │ 110... │ [收起]   │
│  ↑ 展开后变为：                                                  │
│  ┌──────────────────────────────────────────────────────┐    │
│  │ 姓名:  [张三________]  单位: [30所________]             │    │
│  │ 职务:  [高工________]  电话: [13812345678]            │    │
│  │ 身份证: [110101199001011234]                            │    │
│  │                              [保存修改] [取消]          │    │
│  └──────────────────────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────────┘
```

### 4.3 底部按钮栏

```
┌──────────────────────────────────────────────────────────────┐
│  [← 返回上一步]      确认 84 条      [确认导入 →]                │
└──────────────────────────────────────────────────────────────┘
```

左下："返回上一步"（灰底）—— 跳 /experts/import，保留列映射和文件
中下：动态显示"确认 X 条"（X = 当前状态为确认的行数）
右下："确认导入"（绿底）—— 跳 /experts/import/done，提交数据库

### 4.4 字段为空时的视觉

- 字段值为空时显示灰色"-"（短横线），不是空白
- 身份证号 / 电话等长字段超出 8 个字符时尾部用...省略，hover 显示完整值
- 行内编辑时所有字段可改，长字段不省略

## 6. 列表页入口（专家列表页 /experts/）

```
┌──────────────────────────────────────────────────────────────┐
│  专家信息库                                  [+ 添加] [📥 导入]   │
│                                                              │
│  [搜索框]  [筛选]                                              │
│  ...                                                          │
└──────────────────────────────────────────────────────────────┘
```

"导入"按钮：
- 位置：列表页右上角"添加"按钮旁边
- 样式：白底蓝字（区别于"添加"的实心蓝底）
- 图标：📥 入箱图标
- 文案："导入"
- 跳转：/experts/import
- 可见性：**全员可见**

## 7. 颜色与图标规范

### 颜色
- 主色：#0d6efd（Bootstrap 蓝）—— 按钮、链接
- 成功：#198754（绿）—— ✓ 待确认、导入成功
- 警告：#ffc107（黄）—— ⊘ 跳过（缺姓名）
- 失败：#dc3545（红）—— ✗ 失败
- 辅助：#6c757d（灰）—— "忽略此列"、次要按钮

### 图标
- ✓ 确认
- ⊘ 跳过
- ✗ 失败
- → 下一步
- ← 返回
- 📥 导入
- + 添加

## 8. 响应式

- 桌面（≥992px）：完整布局
- 平板（768~991px）：步骤指示器保留，中部表格横向滚动
- 手机（<768px）：本期不专门适配（科研管理系统的核心使用场景是桌面）

## 9. 错误提示样式

错误提示统一用 Bootstrap Alert 组件：
- 位置：页面顶部（步骤指示器下方）
- 样式：红底白字 + 关闭按钮
- 自动消失：3 秒后渐隐（成功提示）/ 不自动消失（错误提示）
- 文案：精炼，不超过 30 字

## 10. 不在 UI 设计范围

- 主题切换（暗色模式）
- 多语言（i18n）
- 拖拽上传的多文件支持（一次只导一个）
- 导入进度的实时显示（已确定不做异步）
- 撤销导入按钮（导入成功后只能逐条删除）
