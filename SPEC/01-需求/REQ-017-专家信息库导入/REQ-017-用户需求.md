# REQ-017 专家信息库导入

## 1. 背景

专家信息库目前有完整的增删改查（列表 / 添加 / 编辑 / 删除 / 导出），但**没有批量导入**入口。当需要一次性录入数十到数百位专家时，只能逐个手工添加，效率极低且容易出错。

设备知识库的导入功能（REQ-011 / REQ-012）已实现成熟方案：上传 xlsx + 列映射下拉 + 逐行确认 + 批量提交。本需求在参照设备导入实现的同时，**根据专家表的字段特点做必要的简化**。

## 2. 目标

提供一条"上传 xlsx → 调整列映射 → 预览确认 → 批量提交"的标准导入链路，单次最多支持 1000 条记录。

## 3. 用户场景

- 场景 A：新单位接入，需要把 50~200 位现役专家一次性录入系统
- 场景 B：人员调整后，把新一批专家信息补录到系统
- 场景 C：人事部门提供的 Excel 名册转换后导入

## 4. 功能范围

### 4.1 必须实现

- 上传 .xlsx 文件
- 第一步：解析表头 + 显示 Excel 前 10 行预览，让用户判断格式
- 第一步：**列映射下拉**——每个 Excel 列对应一个下拉框，让用户选这个列映射到哪个专家字段
- 第一步：**智能提示**——Excel 列名包含"姓名""电话""身份证"等关键字时，自动预选对应字段
- 第二步：解析每行数据，按列映射转换字段
- 第二步：逐行预览，**校验必填字段 name**（缺失则该行标红"跳过"）
- 第二步：用户可逐行操作：**确认** / **跳过** / **修改后确认**
- 第二步：批量确认后点击"确认导入"
- 第三步：提交结果页（成功 X 条 / 跳过 Y 条 / 失败 Z 条 + 失败原因列表）

### 4.2 必须不实现（参照设备导入但简化掉）

- **智能匹配单位**——专家表 unit 是单值文本字段，不做"精确/模糊/未匹配"的多值解析
- **关联设备选择**——专家表无关联字段
- **重复处理弹窗**——expert_id 由系统自动生成，导入永远不重复；name 允许重名（同人同名是正常的）
- **异步进度 / SSE**——1000 条以内同步执行足够快，不需要进度推送
- **批量分类选择**——专家表无 category 字段

## 5. 字段映射规则

专家表 13 个字段中，**导入可用的字段有 10 个**：

| Excel 列可选字段 | 数据库字段 | 是否必填 | 备注 |
|---|---|---|---|
| 姓名 | name | **是** | 缺则整行跳过 |
| 单位 | unit | 否 | |
| 职务 | position | 否 | |
| 专长 | expertise | 否 | |
| 银行卡号 | bank_card | 否 | |
| 开户行 | bank_name | 否 | |
| 上传人 | uploader | 否 | 默认填当前登录用户名 |
| 电话 | phone | 否 | |
| 身份证号 | id_card | 否 | |

**不可导入的字段 3 个**：
- `id`（主键自增）
- `expert_id`（业务编号，**由系统自动生成**，用户不可导入也不可手工填写）
- `created_at` / `updated_at`（系统时间戳）

## 6. 智能提示规则

列映射下拉打开时，按以下规则预选第一个匹配项，用户可改：

| Excel 列名包含关键字 | 预选字段 |
|---|---|
| 姓名 / 名字 / name | name |
| 单位 / 部门 / 机构 / unit | unit |
| 职务 / 岗位 / 职位 / position | position |
| 专长 / 特长 / 研究方向 / expertise | expertise |
| 电话 / 手机 / 联系方式 / phone | phone |
| 身份证 / 证件号 / id_card | id_card |
| 银行卡 / 银行账号 / bank_card | bank_card |
| 开户行 / bank_name | bank_name |
| 上传人 / uploader | uploader |

预选冲突时按"先匹配先得"——按上表顺序遍历 Excel 列，第一个有匹配的字段被占用，后续同名字段下拉里就不再包含该字段。

## 7. expert_id 自动生成规则

- 格式：`EXP-yyyyMMdd-XXXX`（年-月-日-4 位流水号）
- 每天从 0001 开始
- 同一秒内多次导入时，流水号递增避免重复
- 由后端在写入数据库前生成，前端不需要关心

## 8. 限制与边界

- 单次导入上限 **1000 条**（超出提示"请拆分多次导入"）
- 支持 .xlsx 格式（不兼容 .xls / .csv——可后续扩展）
- 文件大小上限 20MB
- 列映射必须把"姓名"列映射到 name 字段，否则无法进入下一步
- 至少要有 1 行数据（不含表头），否则提示"文件为空"
- 同一字段不能被多列映射（同一 name 字段只能被一个 Excel 列选）
- 不做实时格式校验（电话/身份证号）——写入时只做长度截断，不做语义校验

## 9. 权限与流程

- **全员可导入**（不限制管理员角色）——所有登录用户都能看到导入入口并执行导入
- 上传后文件不保存到磁盘（仅在内存解析，导入完成后丢弃）
- 导入过程中刷新页面会丢失 session 中的预览数据，需重新上传
- 导入失败的行不会写入数据库，成功行才会

## 10. 不在本期范围

- .xls（老版本 Excel）支持
- .csv 支持
- 电话号码格式校验
- 身份证号真实性校验（公安接口）
- 专家头像 / 附件上传
- 专家分组（已通过独立的"专家组管理"模块管理，导入时不涉及）
- 撤销导入 / 批量回滚（导入成功后只能逐条删除）
