## 1. 路由清单

在 `app/routes/experts.py` 新增 4 个路由（与设备导入的命名风格一致）：

| 方法 | 路径 | 作用 | 返回 |
|---|---|---|---|
| GET | `/experts/import` | 步骤 1：上传页 | 渲染 import_step1.html |
| POST | `/experts/import/preview` | 步骤 1 提交：解析 + 列映射 + 跳步骤 2 | 重定向 /experts/import/preview (GET) |
| GET | `/experts/import/preview` | 步骤 2：渲染预览页 | 渲染 import_step2.html |
| POST | `/experts/import/commit` | 步骤 2 提交：批量写入 | 重定向 /experts/import/done |
| GET | `/experts/import/done` | 步骤 3：结果展示 | 渲染 import_done.html |

**session 状态约定**：
- `session['expert_import_data']`：步骤 1→2 期间保存原始解析数据（list of dict）
- `session['expert_import_filename']`：原始文件名（用于 done 页显示）
- `session['expert_import_results']`：步骤 2→3 期间保存写入结果（dict of success/skip/fail）

**session 容量评估**：
- 1000 行 × 10 字段 × 平均 20 字符 = 200KB 文本
- Flask 默认 cookie session 上限 4KB → 严重超限
- **方案**：步骤 1 解析 + 步骤 2 渲染走**同一次 POST**（不在中间存 session），步骤 2 提交后**立即写库并把结果存 session**（结果数据量小：1000 条的 success 列表 = 1000 个 expert_id 字符串 × 20 字符 = 20KB，仍超 4KB）
- **真正方案**：步骤 2 提交后**不存结果到 session**，而是把 task_id 存 session，结果用 task_id 存到 `data/expert_import_tasks/<task_id>.json`，done 页读这个文件。**避免 session 超限**

简化方案采用：
- 步骤 1 POST → 步骤 2 GET：session 只存**轻量数据**（filename + column_mapping + headers），步骤 2 渲染时**重新从上传文件读**
- 等等，文件上传后只在请求中存在，刷新就丢

**最终采用**（参考设备导入的实际做法）：
- 步骤 1 GET：空表单
- 步骤 1 POST：上传文件 + 列映射，**session 存 headers + column_mapping + data_rows**（data_rows 是 list of dict，已解析成纯字符串）
- 评估：1000 行 × 10 字段 × 20 字符 = 200KB，但 Flask session 是用 `itsdangerous` 签名 cookie，**默认 4KB** 限制
- **设备导入怎么处理的**？需要参考（见 §4.2）

设备导入的实际做法：步骤 1 POST 是 `preview_only=1` 模式（只返回 headers + preview_rows 给前端 JSON，**不在 session 存任何数据**），前端 JS 拿到 JSON 后**完全在前端处理列映射**，列映射完成后**点"下一步"时再 POST 完整文件 + 列映射**，后端重新解析生成 session 里的 processed。

**所以专家导入照搬**：
- 步骤 1 GET：空表单
- 步骤 1 POST preview_only=1：返回 headers + preview_rows 给前端，**不在 session 存**
- 前端 JS：智能预选列映射 + 用户调整 + 显示校验
- 点"下一步"时：前端用 FormData 重新发文件 + column_mapping
- 步骤 1 POST（无 preview_only）：后端**重新解析整个文件**，按列映射转换，存 `session['expert_import_processed']`（含 data_rows + statistics + filename + column_mapping）
- 步骤 2 GET：从 session 读 processed 渲染
- 步骤 2 POST commit：写库，跳 done
- 步骤 3 GET done：从 session 读 results 渲染

这样 session 里只存"已解析的 list of dict"（步骤 1→2 之间）和"结果统计"（步骤 2→3 之间），不存原始 Excel。

### 2.1 新增方法

```python
def generate_expert_id(self) -> str:
    """
    生成专家编号，格式 EXP-yyyyMMdd-XXXX
    查当天已存在的最大流水号，+1 返回
    流水号范围 0001~9999
    """
    today = datetime.now().strftime('%Y%m%d')
    prefix = f'EXP-{today}-'
    conn = self.get_db()
    c = conn.cursor()
    c.execute(
        "SELECT expert_id FROM experts WHERE expert_id LIKE ? ORDER BY expert_id DESC LIMIT 1",
        (prefix + '%',)
    )
    row = c.fetchone()
    conn.close()
    if row:
        last_seq = int(row[0].split('-')[-1])
        new_seq = last_seq + 1
    else:
        new_seq = 1
    if new_seq > 9999:
        raise ValueError(f'今日 ({today}) 导入已达 9999 条上限，请明日再试')
    return f'{prefix}{new_seq:04d}'

def insert_batch(self, experts_data: list, uploader: str) -> dict:
    """
    批量插入专家记录
    :param experts_data: [{'name': ..., 'unit': ..., ...}, ...]
    :param uploader: 上传人（session['name']）
    :return: {
        'success': [{'expert_id': ..., 'name': ..., 'unit': ...}, ...],
        'fail': [{'row_idx': ..., 'name': ..., 'reason': ...}, ...]
    }
    注意：name 校验在调用前完成，调用方确保 data 里每条都有非空 name
    """
    results = {'success': [], 'fail': []}
    now = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
    conn = self.get_db()
    c = conn.cursor()
    for row in experts_data:
        try:
            expert_id = self.generate_expert_id()
            c.execute('''
                INSERT INTO experts
                (expert_id, name, unit, position, expertise,
                 bank_card, bank_name, uploader, created_at, updated_at,
                 phone, id_card)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            ''', (
                expert_id,
                row.get('name', '').strip(),
                row.get('unit', '').strip(),
                row.get('position', '').strip(),
                row.get('expertise', '').strip(),
                row.get('bank_card', '').strip(),
                row.get('bank_name', '').strip(),
                uploader,
                now, now,
                row.get('phone', '').strip(),
                row.get('id_card', '').strip(),
            ))
            conn.commit()
            results['success'].append({
                'expert_id': expert_id,
                'name': row.get('name', ''),
                'unit': row.get('unit', ''),
            })
        except Exception as e:
            conn.rollback()
            results['fail'].append({
                'row_idx': row.get('_row_idx', -1),
                'name': row.get('name', ''),
                'reason': str(e)[:200],
            })
    conn.close()
    return results
```

```python
@bp.route('/import/preview', methods=['POST'])
def import_preview():
    if 'user' not in session:
        return jsonify({'success': False, 'message': '未登录'})

    if 'file' not in request.files:
        return jsonify({'success': False, 'message': '请上传文件'})
    file = request.files['file']
    if not file.filename.endswith(('.xlsx', '.xls')):
        return jsonify({'success': False, 'message': '请上传 xlsx 格式文件'})
    if file.filename.endswith('.xls'):
        return jsonify({'success': False, 'message': '暂不支持 .xls 格式，请另存为 .xlsx 后重试'})

    preview_only = request.form.get('preview_only', '') == '1'

    try:
        from io import BytesIO
        import openpyxl
        stream = BytesIO(file.read())
        workbook = openpyxl.load_workbook(stream, data_only=True)
        ws = workbook.active
        all_rows = [list(r) for r in ws.iter_rows(values_only=True)]

        if len(all_rows) < 2:
            return jsonify({'success': False, 'message': '文件无数据行（少于 2 行）'})

        headers = [str(h).strip() if h is not None else '' for h in all_rows[0]]
        data_rows = all_rows[1:]

        if len(data_rows) > 1000:
            return jsonify({'success': False, 'message': f'超出 1000 条上限（当前 {len(data_rows)} 条），请拆分'})

        # preview_only 模式：只返回表头 + 前 10 行
        if preview_only:
            preview = [[str(c) if c is not None else '' for c in r] for r in data_rows[:10]]
            return jsonify({
                'success': True,
                'headers': headers,
                'preview_rows': preview,
                'total_rows': len(data_rows),
            })

        # 完整模式：接收列映射 + 解析全部行
        import json
        try:
            column_mapping = json.loads(request.form.get('column_mapping_json', '{}'))
        except Exception:
            return jsonify({'success': False, 'message': '列映射参数错误'})

        # 按列映射转换
        processed = []
        for row_idx, row in enumerate(data_rows):
            record = {'_row_idx': row_idx}
            for excel_col_idx, db_field in column_mapping.items():
                if not db_field or db_field == '__ignore__':
                    continue
                if db_field not in ('name', 'unit', 'position', 'expertise',
                                    'phone', 'id_card', 'bank_card', 'bank_name', 'uploader'):
                    continue
                col_idx = int(excel_col_idx)
                if col_idx < len(row):
                    val = row[col_idx]
                    record[db_field] = str(val).strip() if val is not None else ''
                else:
                    record[db_field] = ''
            # 默认 uploader
            record.setdefault('uploader', session.get('name', ''))
            processed.append(record)

        # 校验必填 name
        valid = [r for r in processed if r.get('name', '').strip()]
        skip = [r for r in processed if not r.get('name', '').strip()]

        statistics = {
            'total': len(processed),
            'valid': len(valid),
            'skip': len(skip),
            'filename': file.filename,
        }

        # 存 session
        session['expert_import_data'] = {
            'filename': file.filename,
            'column_mapping': column_mapping,
            'processed': processed,
            'statistics': statistics,
        }

        return jsonify({'success': True, 'redirect': url_for('.import_preview_page')})

    except Exception as e:
        return jsonify({'success': False, 'message': f'解析失败：{str(e)[:200]}'})
```

```python
@bp.route('/import/commit', methods=['POST'])
def import_commit():
    if 'user' not in session:
        return jsonify({'success': False, 'message': '未登录'})

    data = session.get('expert_import_data')
    if not data:
        return jsonify({'success': False, 'message': '会话已过期，请重新导入'})

    import json
    try:
        confirmed = json.loads(request.form.get('confirmed_rows', '[]'))
    except Exception:
        return jsonify({'success': False, 'message': '参数错误'})

    # 调用 ExpertModel.insert_batch
    from app.models import ExpertModel
    model = ExpertModel()
    uploader = session.get('name', '')
    results = model.insert_batch(confirmed, uploader)

    # 存结果到 session（轻量：只存 success 的 expert_id/name/unit + fail 的 row_idx/reason）
    session['expert_import_results'] = {
        'success': results['success'],
        'fail': results['fail'],
        'skip': data['statistics']['skip'],
        'filename': data['filename'],
    }
    session.pop('expert_import_data', None)

    return jsonify({'success': True, 'redirect': url_for('.import_done_page')})
```

```javascript
// 1. 上传文件触发 preview_only
let headers = [];
let previewRows = [];
let columnMapping = {};  // {excel_col_idx_str: db_field_or_ignore}

async function uploadFile(file) {
    const fd = new FormData();
    fd.append('file', file);
    fd.append('preview_only', '1');
    const r = await fetch('/experts/import/preview', { method: 'POST', body: fd });
    const data = await r.json();
    if (!data.success) { alert(data.message); return; }
    headers = data.headers;
    previewRows = data.preview_rows;
    renderPreviewTable();
    renderMappingRows();

// 2. 智能预选（按关键字匹配）
const KEYWORD_MAP = {
    'name|姓名|名字': 'name',
    'unit|单位|部门|机构': 'unit',
    'position|职务|岗位|职位': 'position',
    'expertise|专长|特长|研究方向': 'expertise',
    'phone|电话|手机|联系方式': 'phone',
    'id_card|身份证|证件号': 'id_card',
    'bank_card|银行卡|银行账号': 'bank_card',
    'bank_name|开户行': 'bank_name',
    'uploader|上传人': 'uploader',
};

function autoMap() {
    columnMapping = {};
    const usedFields = new Set();
    headers.forEach((h, idx) => {
        const lower = h.toLowerCase();
        for (const [kws, field] of Object.entries(KEYWORD_MAP)) {
            if (usedFields.has(field)) continue;
            for (const kw of kws.split('|')) {
                if (lower.includes(kw)) {
                    columnMapping[idx] = field;
                    usedFields.add(field);
                    return;
                }
            }
        }
        columnMapping[idx] = '__ignore__';
    });
    renderMappingRows();
    validateMapping();
}

// 3. 实时校验
function validateMapping() {
    const nameMapped = Object.values(columnMapping).includes('name');
    const nextBtn = document.getElementById('nextBtn');
    if (!nameMapped) {
        nextBtn.disabled = true;
        document.getElementById('mapValidation').innerHTML =
            '<div class="alert alert-danger">姓名列未映射，无法继续</div>';
    } else {
        nextBtn.disabled = false;
        document.getElementById('mapValidation').innerHTML = '';
    }
}

// 4. 下一步：发完整文件 + 列映射
async function nextStep() {

        alert(data.message);
    }
}
```

```javascript
// 3. 提交
async function commitImport() {
    const checked = [];
    document.querySelectorAll('input[type=checkbox][name^=confirm_]:checked').forEach(cb => {
        const rowIdx = cb.name.replace('confirm_', '');
        const record = {};
        ['name', 'unit', 'position', 'expertise', 'phone', 'id_card', 'bank_card', 'bank_name'].forEach(f => {
            const input = document.querySelector(`input[name=${f}_${rowIdx}]`);
            if (input && input.value.trim()) record[f] = input.value.trim();
        });
        record._row_idx = parseInt(rowIdx);
        checked.push(record);
    });
    if (checked.length === 0) {
        alert('没有勾选任何行');
        return;
    }
    const fd = new FormData();
    fd.append('confirmed_rows', JSON.stringify(checked));
    const r = await fetch('/experts/import/commit', { method: 'POST', body: fd });
    const data = await r.json();
    if (data.success) window.location.href = data.redirect;
    else alert(data.message);
}
```

## 7. 关键风险点

### 7.1 session 容量

- Flask 默认 cookie session 4KB 上限
- 1000 行 × 10 字段 × 20 字符 ≈ 200KB 文本 → 严重超限
- **方案**：processed 数据**不存 session**，改为步骤 1 POST 后用临时文件保存 + 步骤 2 GET 时读临时文件
- **临时文件清理**：步骤 2 提交时删临时文件
- **临时文件命名**：`tmp/expert_import/<task_id>.json`（task_id = uuid4）
- **session 存什么**：task_id + column_mapping + filename（< 1KB）

### 7.2 必填字段校验

- name 缺失的行**不能**勾选"确认"——前端 disabled checkbox + 后端再次校验
- 步骤 2 提交时后端**忽略**未勾选的行，只处理勾选的

### 7.3 数据库并发

- generate_expert_id 是"读 max + +1"两步操作，**非原子**
- 1000 行单次导入：单线程顺序生成，**并发风险低**
- 如果两个用户同时导入：可能生成相同 expert_id → 触发 UNIQUE 约束失败
- **解决方案**：try/except 捕获 IntegrityError，**重新生成 expert_id** 重试一次

### 7.4 大 Excel 解析

- 1000 行 × 10 列的 Excel 解析耗时 < 1 秒
- openpyxl 默认是 lazy 加载，**对内存友好**
- 无需特殊处理
