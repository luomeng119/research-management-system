**source 字段语法：**

| source 值 | 说明 |
|-----------|------|
| `user_input` | 手动填写（表单留空） |
| `session.name` | 当前用户姓名 |
| `session.dept` | 当前用户部门 |
| `invoice:航空行程单.amount` | 从匹配类型的发票取 amount 字段 |
| `invoice:航空行程单.amount_sum` | 从匹配类型的发票汇总 amount |
| `payment:银行卡.amount` | 从匹配类型的支付记录取 amount |
| `payment:银行卡.amount_sum` | 从匹配类型的支付记录汇总 |
| `calculated:amount_to_cn` | 自动计算（金额→中文大写） |
| `calculated:date_range` | 自动计算（起始日期-截止日期） |
| `null` | 无来源，静态文字 |

## 四、document_engine.py 核心逻辑

```python
# app/document_engine.py

from docx import Document
from docx.shared import Pt
import json, copy

class DocumentFiller:
    """Word 模板填充引擎"""

    def __init__(self, template_dir):
        self.template_dir = Path(template_dir)

    def load_template(self, doc_type):
        """加载模板定义和原始 docx 文件"""
        tpl_dir = self.template_dir / doc_type
        meta = json.loads((tpl_dir / 'template.json').read_text(encoding='utf-8'))
        docx_path = tpl_dir / meta['docx_filename']
        doc = Document(docx_path)
        return meta, doc

    def fill(self, doc, field_values):
        """
        将 field_values {field_id: value} 填入 docx 的表格单元格
        field_id 格式: "T0[3,2]" = Table0 Row3 Col2
        """
        for table_idx, table in enumerate(doc.tables):
            for row_idx, row in enumerate(table.rows):
                for col_idx, cell in enumerate(row.cells):
                    field_id = f"T{table_idx}[{row_idx},{col_idx}]"
                    if field_id in field_values and field_values[field_id]:
                        cell.text = str(field_values[field_id])

    def generate_document(self, doc_type, field_values) -> bytes:
        """生成填充后的 docx，返回字节串（供下载）"""
        meta, doc = self.load_template(doc_type)
        self.fill(doc, field_values)

        # 计算中文大写等自动字段
        field_values = self.resolve_calculated_fields(meta, field_values)
```
