# REQ-004 UI 设计方案

## 基本信息

- **需求编号**：REQ-004
- **需求名称**：报销单据模板管理
- **状态**：阶段三完成，待代码设计确认

---

## 页面清单

本需求共 4 个页面，统一继承报销功能区的页面风格（参考 `records.html`），顶部 Tab 导航复用报销模块布局。

| 序号 | 页面 | 路由 | 权限 |
|------|------|------|------|
| 1 | 报销单据入口页 | `/expense/documents` | 全部用户 |
| 2 | 模板管理页 | `/expense/documents/templates` | 管理员 |
| 3 | 新建单据页 | `/expense/documents/new` | 全部用户 |
| 4 | 汇总打印页 | `/expense/reimbursements/<rid>/print` | 全部用户 |

### 字段来源下拉选项

| 选项 | 说明 |
|------|------|
| `user_input` | 手动填写 |
| `session.name` | 当前用户姓名 |
| `session.dept` | 当前用户部门 |
| `invoice.date` | 从发票提取日期 |
| `invoice.amount` | 从发票提取金额 |
| `invoice.amount_sum` | 从同类发票汇总金额 |
| `payment.amount_sum` | 从支付记录汇总 |
| `calculated` | 自动计算（大写金额等） |
| `null` | 无来源，纯静态文字 |

## 页面 3：新建单据页

**路由**：`GET /expense/documents/new`
**权限**：全部用户
**布局**：左侧表单 + 右侧预览

```
┌────────────────────────────────────────────────────────────────┐
│  报销单据  >  新建单据                                           │
│                                                                │
│  ┌────────────────────────┐  ┌──────────────────────────────┐ │
│  │  步骤 1：选择报销项     │  │                              │ │
│  │  [下拉：选择报销项    ▼] │  │     Word 模板实时预览        │ │
│  │                        │  │                              │ │
│  │  步骤 2：选择模板       │  │   报销单位：________________ │ │
│  │  ○ 差旅费报销凭证       │  │   姓名：__________________  │ │
│  │  ○ 因公出差审批单       │  │   到达地点：________________ │ │
│  │  ○ 伙食补助费申报表     │  │   ...                        │ │
│  │  ○ 科研物资采购申请单   │  │                              │ │
│  │                        │  │                              │ │
│  │  步骤 3：自动填充       │  │                              │ │
│  │  [开始自动填充]         │  │                              │ │
│  │  ← 关联发票/支付记录   │  │                              │ │
│  │                        │  │                              │ │
│  │  步骤 4：确认并保存     │  │                              │ │
│  │  [保存单据]             │  │                              │ │
│  └────────────────────────┘  └──────────────────────────────┘ │
└────────────────────────────────────────────────────────────────┘
```

### 操作流程

1. **选择报销项**：下拉选择当前用户的某个报销项（用于关联发票/支付记录）
2. **选择模板**：单选模板类型
3. **自动填充**：
   - 点击"开始自动填充"
   - 后端根据模板 `source` 规则，从该报销项的发票/支付记录中提取数据
   - 弹窗显示：哪些字段自动填入了什么值，哪些字段无法自动填充（需手动填写）
4. **手动补充**：对无法自动填充的字段，表单中显示为可编辑输入框
5. **实时预览**：右侧 Word 模板预览区同步更新
6. **保存**：提交后跳转到报销项详情页，显示已创建的单据

### 表单字段

每个字段显示为一行：

```
[字段名]  [值输入框（已自动填充的显示为只读）]  [来源标签：发票提取/手动填写]
```

### 错误处理

- 未选择报销项时，"选择模板"区域禁用
- 无关联发票时，自动填充仅填充 session 基础信息，其他字段标记为"无数据"

### 单据卡片

每个已填写的单据卡片显示：
- 勾选框（默认全部勾选）
- 单据类型 + 创建时间
- 字段值摘要（如：姓名+日期+金额）
- "查看"按钮 → 弹窗展示已填写的完整内容

### 未填写单据

灰显卡片，显示"未填写"，不参与打印。

### 发票/支付记录勾选

列出该报销项关联的所有发票和支付记录，供用户选择哪些附在打印包中。

### Word 合并逻辑

1. 遍历选中的 `expense_document`，每个生成一个独立 docx（python-docx 填充）
2. 将所有 docx 用 `docxcompose` 或手动 XML 合并为一个文档
3. 发票图片作为附录页附加在最后
4. 返回合并后的 Word 文件供下载

### 打印预览

点击"打印预览" → 新窗口展示合并后文档的 HTML 预览（仅展示结构，不需要完美还原 Word 样式）。

## 页面风格规范

所有 4 个页面遵循以下规范，与报销模块现有风格保持一致：

| 元素 | 规范 |
|------|------|
| 字体 | 系统默认 sans-serif |
| 颜色 | 主色 `#1f6feb`，背景 `#f5f5f5`，卡片白底 |
| 按钮 | 蓝底白字主按钮，灰边次要按钮 |
| 卡片 | 白色背景，`border-radius: 8px`，`box-shadow: 0 2px 8px rgba(0,0,0,0.1)` |
| 表单 | 标签左对齐，输入框 `height: 36px` |
| Tab | 顶部水平 Tab，下划线高亮当前选中 |
| 布局 | 响应式，宽度 < 768px 时卡片垂直堆叠 |
