# REQ-005：报销单据自动填充增强（OCR识别 + 页面布局优化）

## 用户需求

### 需求一：OCR自动填充
用户点击「自动填充」按钮时，一次性对报销项关联的火车票、航空行程单、电子发票执行OCR识别，
提取结构化信息填充到四个模板字段。同一票据同一会话内不重复OCR。

### 需求二：Word样式页面布局
四类单据的自动填充表单，按Word模板的行列表格样式排列字段。

## OCR提取规则

### 火车票
- **车次**: `r'\b(G\d+|D\d+|K\d+|Z\d+|T\d+|C\d+)\b'`
- **出发站**: 第一个"XX站"，排除北京关键词
- **到达站**: 最后一个"XX站"
- **出发日期**: `r'(\d{4})年(\d{1,2})月(\d{1,2})日'` + 出发时间上下文
- **到达日期**: 同出发日期（火车票一般当日）
- **座位**: `r'(二等座|一等座|商务座|硬卧|软卧|无座)'`

### 航空行程单
- **航班号**: `r'\b([A-Z]{2}\d{3,4})\b'`
- **出发/到达机场**: 城市名+机场关键字匹配
- **出发/到达日期时间**: 正则提取

### 电子发票/商品明细
- 取 `items` 数组，每个 item 提取: name, spec, qty, price, amount

---

## 关键规则

- **北京排除**: {'北京','北京南','北京北','北京西','北京东','北京站','Beijing','BEIJING'}
- **城市列表**: 所有票据城市去北京后去重，顿号连接
- **日期范围**: `YYYY-MM-DD ~ YYYY-MM-DD`
- **出行方式**: 仅高铁→"高铁"；仅航空→"飞机"；两者都有→"高铁+飞机"；无→留空
- **OCR缓存**: 内存 dict，key=invoice_id，同一会话不重复识别

## Word样式表格布局

### 解析逻辑
`field_id` 格式 `T{table_index}[{row},{col}]` → 按 table_index 分组，按 row/col 排序构建 HTML table。
- 同行连续单元格合并（识别 colspan）
- label 列和输入列在同一行
- 输出 `<table class="table table-bordered">` 结构

### 动态行（科研物资采购申请单）
当有多个商品明细时，在模板固定行之后动态插入物品明细行：
```html
<tr class="item-row" data-item-index="0">
  <td><input id="field_T0[3,1]" data-source="invoice:商品名称[0]"></td>
  ...
</tr>
```
