## UI 整体架构

两个模块共用同一套页面风格，宿主设备库用蓝色调，设备知识库用绿色调。

**三个页面**：
1. **导入上传页**（步骤1）：文件上传 + 列映射
2. **匹配预览页**（步骤2）：预览 + 修正 + 辅助整理
3. **结果页**（步骤3）：导入完成，汇总报告

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 宿主设备库 - 导入预览（步骤2/3）                                     [上一步] │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  文件: 某某单位设备清单.xlsx   │  总计: 8行  ✓精确4  ~模糊3  ⚠未匹配1  │
│                                                                         │
│  ┌─ 关联设备匹配 ────────────────────────────────────────────────────┐  │
│  │  [全部] [精确✓] [模糊~] [未匹配⚠] [重复⚠]                        │  │
│  └──────────────────────────────────────────────────────────────────┘  │
│                                                                         │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │ #  │ 宿主设备名称  │ 类型     │ 关联密码设备                    │  │
│  ├────┼───────────────┼──────────┼────────────────────────────────┤  │
│  │ 1  │ 战术指挥车    │ 通信电台 │ ✓ 数据中心服务器               │  │
│  │    │              │          │ ✓ XX-200密码设备                │  │
│  │    │              │          │ ✓ 数据链网关                    │  │
│  ├────┼───────────────┼──────────┼────────────────────────────────┤  │
│  │ 2  │ 数据中心服务器│ 计算存储 │ ~ XX-200密码设 [▼ 改为: XX-200]│  │
│  │    │              │          │   [候选: XX-200密码设备V2]       │  │
│  ├────┼───────────────┼──────────┼────────────────────────────────┤  │
│  │ 3  │ 移动指挥所    │ 通信电台 │ ⚠ 未找到匹配                  │  │
│  │    │              │          │   [▼ 选择设备...]                │  │
│  ├────┼───────────────┼──────────┼────────────────────────────────┤  │
│  │ 4  │ 备件库        │ 计算存储 │ ⚠ 已存在 [覆盖▼] [跳过] [新建] │  │
│  └────┴───────────────┴──────────┴────────────────────────────────┘  │
│                                                                         │
│  ┌─ 辅助信息 ───────────────────────────────────────────────────────┐  │
│  │  宿主机类型统计: 通信电台 3 / 计算存储 2 / 数据链 1 / 新增类型 1  │  │
│  └──────────────────────────────────────────────────────────────────┘  │
│                                                                         │
│  [导出匹配报告]                                        [上一步] [导入]  │
└─────────────────────────────────────────────────────────────────────────┘
```

**操作说明**：

- `✓ 精确`：无需操作，直接关联
- `~ 模糊`：下拉选择候选中正确的一项，或手动搜索选择，或跳过
- `⚠ 未匹配`：「选择设备...」弹出模糊搜索下拉框，手动选或跳过
- `⚠ 重复`：选择「覆盖」（用Excel数据更新）、「跳过」（保留原数据）、「新建」（生成新host_id）
