## 一、背景与现实场景

用户在整理设备数据时，手头有各种 Excel 设备清单（来自不同来源/不同时间），其中有一列「关联密码设备」或「关联宿主设备」，填写的是另一方设备的名称或型号。由于存在打字错误、名称差异（如「XX-200密码设备V2」vs「XX-200密码设备」），传统精确匹配无法关联上。

---

## 二、核心功能（五件事）

### 第一件事：共用模糊匹配函数工具模块

独立工具模块 `app/utils/fuzzy_match.py`，对外暴露三个函数：

| 函数 | 输入 | 搜索目标表 | 用于 |
|------|------|-----------|------|
| `match_equipment(text)` | 密码设备名称/型号 | `equipment` 表 | 宿主设备库导入「关联密码设备」列 |
| `match_host_device(text)` | 宿主设备名称/型号 | `host_devices` 表 | 设备知识库导入「关联宿主设备」列 |
| `match_research_unit(text)` | 研制单位名称 | `research_units` 表 | 设备知识库导入「研制单位」列（REQ-010 提供字典表）|

**输入预处理（多设备名称识别 — 适用于前两个函数）**：
- 收到字符串后，先按顿号「、」和逗号「，」拆分为列表
- 对每个子串单独执行模糊匹配
- 返回结果中标注每个子串的匹配状态

**每个函数实现四级匹配策略**：
1. **精确匹配**：`name = text` 或 `model = text`
2. **去噪声匹配**：去除「型号/」「设备」等噪声词后精确匹配
3. **模糊相似度匹配**：编辑距离 < 3 且长度 > 5，或包含匹配
4. **未匹配**：返回空，交由用户在预览页面手动选择

**返回值结构（统一）**：
```python
{
    'original': '数据中心服务器、XX-200密码设备',
    'items': [
        {
            'name': '数据中心服务器',
            'exact': [设备列表],
            'fuzzy': [设备列表],
            'status': 'exact',         # exact | fuzzy | unmatched
            'selected': 设备或None
        },
    ]
}
```

### 第二件事：宿主设备库导入增强

- 导入目标：`host_devices` 表
- 关联字段名：「关联密码设备」
- 匹配目标表：`equipment` 表

**三步流程**：

**步骤1：列映射 + 上传**
- 上传 xlsx 文件
- 显示预览表格（数据前3行），系统自动尝试匹配列名
- 每列顶部下拉选择对应字段：
  `[ 编号 ▼ ]  [ 名称 ▼ ]  [ 型号 ▼ ]  [ 类型 ▼ ]  [ 形态 ▼ ]  [ 关联密码设备 ▼ ]  [ 其他字段... ]`
- 关联字段列（关联密码设备）必须指定，未指定则不执行关联匹配
- 用户确认映射关系后进入步骤2

**步骤2：匹配预览（可手动调整）**
- 对「关联密码设备」列按 `match_equipment()` 模糊匹配
- 显示每行匹配状态：✓精确 / ~模糊 / ⚠未匹配
- 对模糊/未匹配行，允许手动选择其他设备或跳过
- 重复检测：按 host_id 查重，提示选择：覆盖 / 跳过 / 新建编号

**步骤3：确认导入**
- 写入 host_devices 表（新增或覆盖）
- 写入 device_host_relations 表（device_id = equipment.equipment_id）

- 导出 xlsx 增加「关联密码设备ID」「关联密码设备名称」列

### 第三件事：设备知识库导入增强

- 导入目标：`equipment` 表
- 关联字段名：「关联宿主设备」「研制单位」（两者都参与导入处理）
- 匹配目标表：`host_devices` 表（把宿主设备名匹配到已有宿主设备）
- 研制单位字典来源：`research_units` 表（由 REQ-010 提供）

**三步流程**：

**步骤1：列映射 + 上传**
- 上传 xlsx 文件
- 显示预览表格（数据前3行），系统自动尝试匹配列名
- 每列顶部下拉选择对应字段：
  `[ 设备编号 ▼ ]  [ 设备名称 ▼ ]  [ 型号 ▼ ]  [ 分类 ▼ ]  [ 研制单位 ▼ ]  [ 形态 ▼ ]  [ 关联宿主设备 ▼ ]  [ 其他字段... ]`
- 关联字段列（关联宿主设备 / 研制单位）必须指定，未指定则不执行关联匹配
- 用户确认映射关系后进入步骤2

**步骤2：匹配预览 + 辅助整理**
- 对「关联宿主设备」列：按 `match_host_device()` 模糊匹配，显示每行状态
- 对「研制单位」列：按分隔符（`、`，`，`，`；`）拆分 → 每个子串 `match_research_unit()` → 合并结果
  - 精确匹配：✓绿色
  - 模糊匹配：~黄色（显示匹配到的标准名称）
  - 未匹配：⚠红色（显示原始输入，可手动选择标准单位或保留原值）
- 对模糊/未匹配行，允许手动选择其他宿主设备或跳过
- 重复检测：按 name+model 查重，提示选择：覆盖 / 跳过 / 新建
- 类型归一：发现未知类型时，提示选择：归入已有类型 / 新建类型

**步骤3：确认导入**
- 写入 equipment 表（新增或覆盖），`manufacturer` 字段存储合并后的标准单位名（如"数据所、30所、722所"）
- 写入 device_host_relations 表（host_id = host_devices.host_id）

- 导出 xlsx 增加「关联宿主设备ID」「关联宿主设备名称」列

### 第四件事：研制单位模糊匹配

`match_research_unit(text)` 函数（`app/utils/fuzzy_match.py`）：

**输入预处理（多单位名称识别）**：
- 收到字符串后，先按「、」「，」「；」拆分为列表
- 对每个子串单独执行模糊匹配
- 最终合并：`merged = '、'.join([u['matched'] for u in units if u['matched']])`

**匹配策略（四级）**：
1. 精确匹配：`unit_name = text.strip()`
2. 去噪声匹配：去除「研究院」「研究所」「中心」「基地」等噪声词后精确匹配
3. 模糊相似度匹配：编辑距离 < 3 且长度 > 4，或包含匹配
4. 未匹配：返回空，交由用户在预览页面手动选择

**返回值结构**：
```python
{
    'original': '数据所、三十所研究院',
    'units': [
        {'original': '数据所',    'matched': '数据所', 'status': 'exact'},
        {'original': '三十所研究院', 'matched': '30所', 'status': 'fuzzy'},
    ],
    'merged': '数据所、30所',
    'has_unmatched': False,
}
```

## 三、两个模块对比

| | 宿主设备库导入 | 设备知识库导入 |
|---|---|---|
| 导入目标表 | `host_devices` | `equipment` |
| 关联字段名 | 关联密码设备 | 关联宿主设备、研制单位 |
| 匹配目标表 | `equipment` | `host_devices` + `research_units` |
| 关联写入 | `device_host_relations.device_id` | `device_host_relations.host_id` |
| 重复检测依据 | `host_id` | `name + model` |
| 类型归一 | 不涉及 | 涉及（equipment.category） |
| 研制单位处理 | 不涉及 | 拆分 + match_research_unit() + 合并写入 |

## 五、REO-010 协同说明

REQ-009 的设备知识库导入「研制单位」列依赖 REQ-010 建立的 `research_units` 字典表和 `match_research_unit()` 函数。

**实施顺序**：
1. 先完成 REQ-010：建立 `research_units` 表、初始数据、`match_research_unit()` 函数
2. 再完成 REQ-009 第三/四件事：扩展设备知识库导入使用研制单位字典

**接口契约**：
- `research_units` 表字段：`unit_id (PK)`, `unit_name`, `created_at`, `updated_at`
- `match_research_unit()` 接收任意研制单位字符串，返回标准化结果
- 若 REQ-010 未完成，设备知识库导入的研制单位列可先跳过字典匹配（提示用户先配置字典）

## 六、边界处理

| 场景 | 处理方式 |
|------|---------|
| Excel 中关联设备名用顿号「、」或逗号「，」分隔多个 | 拆分成多个，分别匹配，每个都建关联 |
| Excel 中研制单位用顿号/逗号分隔多个 | 拆分成多个，分别 match_research_unit()，合并后写入 manufacturer |
| 某设备名称在 Excel 中出现多次 | 每次出现都建关联 |
| 匹配目标表为空 | 目标表本身可正常导入，关联跳过 |
| 研制单位字典表为空（REQ-010 未实施） | 研制单位列原样写入，不做匹配 |
| 字段类型错误（如价格填文字） | 标红提示，字段置空，不阻断导入 |
| Excel 某行全空 | 跳过该行 |
| 用户提供的列名与系统期望不符 | 步骤1由用户手动映射列名，支持任意列名 |
