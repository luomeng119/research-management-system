# REQ-016 需求设计

## 1. 用户描述复述

> "通用表格管理功能：
> 1.为每行增加了一个3色块，用于点击设置本行配色。
> 2.列管理增加排序调整功能。
> 3.列宽可通过分割线拖拽调整。
> 4.每页分页数量可设置。"

**关键决策补充**（已与用户确认）：
- 颜色不用循环切换，**3 个独立色块直接显示，用户主动点击**（不是 hover 弹出色板）
- 列宽持久化到后端
- 分页数量持久化到后端（每版本独立）

## 2. 功能理解

| 项 | 当前状态 | 本次要做 |
|---|---|---|
| 行染色 | **无**（行表无 `row_color` 字段） | 新增字段 + 3 色块 UI + toggle 逻辑 |
| 列排序 | 数据模型已有 `col_index` 字段（创建时赋值） | 加拖拽 UI + 保存到后端 |
| 列宽 | 数据模型已有 `col_width DEFAULT 120` | 加表头边缘拖拽 UI + 保存到后端 |
| 分页数量 | 前端硬编码 `const PAGE_SIZE = 20` | 工具栏下拉 + 保存到后端（按 version 隔离） |

## 3. 子需求拆解

### 3.1 数据模型变更

#### A. `generic_table_data` 加 `row_color` 字段

```sql
ALTER TABLE generic_table_data ADD COLUMN row_color TEXT DEFAULT '';
```
- 允许值：`''`（无）/ `'yellow'` / `'green'` / `'red'`
- 默认 `''`（兼容老数据，**不强制补默认值**——读时 fallback 到 `''`）

#### B. `generic_table_versions` 加 `page_size` 字段

```sql
ALTER TABLE generic_table_versions ADD COLUMN page_size INTEGER DEFAULT 20;
```
- 默认 20
- 同一 table 多个 version 各自独立
- 切到「全部」时存 `-1`（特殊值）作为标记

#### C. 列宽 / 列顺序字段已存在

`generic_table_columns.col_index` 和 `col_width` 字段已存在，**无需 ALTER**，只需写新 API 改它们。

### 3.2 API 变更（4 个新端点 + 0 个改）

| 方法 | 路径 | 作用 | 入参 | 返回 |
|---|---|---|---|---|
| PUT | `/api/generic-tables/versions/<vid>/rows/<row_key>/color` | 单行改色 | `{row_color: 'yellow'\|'green'\|'red'\|''}` | `{ok:true, row_color:...}` |
| PUT | `/api/generic-tables/versions/<vid>/columns/reorder` | 批量改列顺序 | `{order: ['col_key1', 'col_key2', ...]}` | `{ok:true}` |
| PUT | `/api/generic-tables/versions/<vid>/columns/<col_key>/width` | 单列改宽 | `{col_width: 200}` | `{ok:true, col_width:...}` |
| PUT | `/api/generic-tables/versions/<vid>/page-size` | 改分页数 | `{page_size: 20\|-1}` | `{ok:true, page_size:...}` |

### 3.3 详细功能点

| 编号 | 功能 | 说明 |
|---|---|---|
| REQ-016-1 | 行表 ALTER 加 row_color 字段 | 兼容老数据，default '' |
| REQ-016-2 | 版本表 ALTER 加 page_size 字段 | default 20 |
| REQ-016-3 | API: PUT row color | 4 个有效值校验 |
| REQ-016-4 | API: PUT columns reorder | 事务原子，全列更新 col_index |
| REQ-016-5 | API: PUT column width | 60 ≤ w ≤ 800 校验 |
| REQ-016-6 | API: PUT version page-size | -1/10/20/50/100 校验 |
| REQ-016-7 | 行 3 色块 UI | 行首 3 个 14×14px 圆角色块：🟡🟢🔴，点击 toggle |
| REQ-016-8 | 行染色持久化 | 调 API，失败时 alert 错误并回滚 UI 状态 |
| REQ-016-9 | 行染色优先级 | row_color > row-selected > row-deleted > row-modified > 默认 |
| REQ-016-10 | 列管理抽屉加拖拽手柄 | col-item 左侧加 ≡ SVG，可拖动 |
| REQ-016-11 | 拖拽视觉 | 拖动项半透明 + 蓝色插入线（HTML5 Drag API 或 SortableJS） |
| REQ-016-12 | 拖拽保存 | dragend 触发 PUT columns reorder |
| REQ-016-13 | 表头边缘 4px 拖拽区 | mouseover 变 col-resize + 蓝线 |
| REQ-016-14 | 拖动改宽 | mousedown/mousemove/mouseup，仅改目标列 width |
| REQ-016-15 | 宽度校验 | 60-800px，超界钳制 |
| REQ-016-16 | 拖拽结束保存 | mouseup 触发 PUT column width |
| REQ-016-17 | 工具栏分页下拉 | 右侧加 `<select>`：[10/20/50/100/全部] |
| REQ-016-18 | 切换分页数 | 调 PUT page-size + 重渲染（重置第 1 页） |
| REQ-016-19 | 后端传 page_size | detail_page 路由读 `version.page_size` 传给前端 |
| REQ-016-20 | 「全部」特殊处理 | page_size=-1 → 前端 PAGE_SIZE = ROWS.length |

### 3.4 关联需求

- 与 **REQ-015 设备列表** 无关（不同模块、不同表）
- 借鉴 REQ-015 的 **错误处理模式**（catch + r.ok + alert(err.message)）

### 3.5 流程图

```
用户打开表格详情页
  ├─ 工具栏读取 version.page_size → 设 PAGE_SIZE
  └─ 主表渲染
      ├─ 每行渲染 3 色块
      └─ 读 row_color 决定行底色

[色块点击]
  → PUT row color → 后端 UPDATE → 改前端状态
  → 行底色立刻变（乐观更新）

[列管理抽屉拖拽]
  → 拖完 → PUT columns reorder → 事务批量 UPDATE col_index
  → 关闭抽屉后主表用新顺序

[表头边缘拖拽]
  → 拖动 → 改 th width + td width (同步)
  → 抬起 → PUT column width → 后端 UPDATE

[分页下拉]
  → 选新值 → PUT page-size → 后端 UPDATE
  → 重渲染（currentPage=1, pageSize=new）
```

### 3.6 场景

| 场景 | 期望 |
|---|---|
| 新建表格（无任何数据） | 3 色块都显示但不影响空状态 |
| 100 行表格，染色第 5 行和第 50 行 | 翻到任意页都能看到颜色 |
| 切到「每页 50 条」 | 翻页器变成 2 页；切回 20 变成 5 页 |
| 拖列宽到 50px | 自动钳制到 60px |
| 网络中断时染色 | alert 错误，行色不变 |
| 列管理拖拽过程中刷新 | 后端未保存，新顺序丢失（属正常情况） |
| 同一表格打开 2 个浏览器 tab 都改列宽 | 后写覆盖先写（last-write-wins；不实现版本冲突） |
| 兼容性（数据库已有数据） | row_color 字段不存在不报错，model 层 try/except 兜底 |
