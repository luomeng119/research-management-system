# REQ-016 用户需求

**项目**：04-科研管理系统
**模块**：通用表格管理 → 详情页（`/tables/<table_id>`）
**版本**：v1
**日期**：2026-06-25

## 业务背景

当前通用表格详情页（设备台账/报销记录/任何自建表）有 4 个能力缺失，影响用户实际录入与阅读体验：

1. 录入 100+ 行数据后，**重点行没有视觉标记**——靠记忆和滚动找，效率低
2. 列管理（增/删/改）能用，但**列顺序只能后端改完刷新才知道**，调整顺序不直观
3. 列宽固定 120px，**长内容（型号/说明）被截断**，需要 hover tooltip 配合才能看全
4. 表格数据超过 20 条就**只能一页页翻**，想看更多必须改前端代码

## 4 个用户故事

### US-1：行染色（视觉标记重点行）
> 作为设备台账录入员
> 我希望对一些重要行（如「待复核」「缺料」「风险项」）用颜色高亮
> 以便录入 200 行后翻页时一眼能找到它们

**验收标准**：
- 表格每行最左侧（选择框之后、序号之前）出现 3 个并排的色块：🟡 黄 / 🟢 绿 / 🔴 红
- 色块默认都不高亮，点击某个色块 → 该行底色变成对应颜色，且那个色块自身加边框表示「当前选中」
- 再次点击**同一个**色块 → 取消染色（恢复默认）
- 点击**不同**色块 → 切换到新颜色（旧色块的选中边框消失，新色块出现）
- 颜色绑定在 `(table_id, version_id, row_key)` 上，刷新页面不丢
- 与现有「行选中」「已删除」「已修改」状态**互斥**（只能存在一种）

### US-2：列排序（拖拽调整列顺序）
> 作为表格配置员
> 我希望在「列管理」抽屉里能拖动列项调整顺序
> 以便把常用列（如「设备名称」「状态」）放到前面

**验收标准**：
- 列管理抽屉里每个列项**左侧**出现「≡」拖拽手柄
- 拖动后该列项变半透明跟随鼠标，鼠标位置显示插入线（蓝色横线）
- 松手后立即保存到后端 `col_index` 字段
- 关闭抽屉回到主表 → 列顺序已生效
- 任何用户/任何设备打开同一个表格，**列顺序一致**（后端持久化）

### US-3：列宽拖拽（手动调整列宽）
> 作为阅读者
> 我希望直接拖动表头右边缘来改变列宽
> 以便长内容（设备型号「KJ-1234-V2.5-MIL」、长说明）能一屏看全

**验收标准**：
- 鼠标移到表头**右边缘 4px 范围**内时，光标变成 `col-resize`
- 该位置出现一条**蓝色竖线**（2px 宽）提示可拖
- 按下拖动 → 该列宽度实时变化（其他列不动，仅当前列变宽/变窄）
- 最小宽度 60px，最大宽度 800px（防止误拖到 0）
- 鼠标抬起后保存到后端 `col_width` 字段
- 刷新页面后该列仍是调整后的宽度
- 同一表格的列宽在所有用户/所有设备上**一致**

### US-4：分页数量可设置
> 作为阅读者
> 我希望在数据多的时候能切到「每页 50 条」或「每页 100 条」
> 以便减少翻页次数

**验收标准**：
- 工具栏右侧（搜索框附近）出现分页下拉：`每页 [10 / 20 / 50 / 100 / 全部]`
- 默认 20
- 切换后立即重新分页，**第 1 页重置**
- 设置保存在后端（每个 `version_id` 独立），刷新页面不丢
- 切到「全部」时取消分页（无分页器），数据显示**当前筛选条件下所有行**
- 同一表格同一版本的设置在所有用户/所有设备上**一致**

## 不在本次范围

- 行染色按**条件自动染色**（如「状态=维修中」自动红）—— 本期只手动
- 列宽双击自适应内容宽度
- 列拖拽时**实时重排主表格**—— 本期只在「列管理」抽屉里调，主表只有关闭抽屉刷新后才看到新顺序
- 多列宽预设方案（如「紧凑/默认/宽松」）—— 简单拖拽
- 分页数量支持自定义数值（必须选预设值）

## 优先级

| 故事 | 优先级 | 备注 |
|---|---|---|
| US-1 行 3 色块 | P0 | 用户明确要求的核心新功能 |
| US-2 列拖拽排序 | P1 | 数据模型已支持 `col_index`，低成本 |
| US-3 列宽拖拽 | P1 | 数据模型已支持 `col_width`，低成本 |
| US-4 分页数量 | P2 | 影响性能时再调；前端硬编码也够用，但持久化更专业 |
