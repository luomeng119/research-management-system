## 一、行 3 色块

### 1.1 色块位置与外观

每行最左端，**选择框之后、序号之前**，横向并排显示 **3 个 14×14 像素的圆角色块**。

```
┌──────┬──┬──┬──┬────────────────────┐
│ ☐    │🟡│🟢│🔴│ 1 │ 设备名称 │ ... │  ← 第 1 行（无染色）
├──────┼──┼──┼──┼────────────────────┤
│ ☐    │🟡│🟢│🔴│ 2 │ XXX     │ ... │  ← 第 2 行（绿色）
└──────┴──┴──┴──┴────────────────────┘
```

### 1.2 色块的三种状态

| 状态 | 视觉 | 含义 |
|---|---|---|
| **未激活** | 实心圆角色块，**无边框** | 该颜色未应用 |
| **已激活** | 实心圆角色块，**加深边框**（如深灰 1.5 像素） | 该颜色已应用到本行，行底色变对应色 |
| **悬停** | 色块**变亮 10%** + 鼠标变手型 | 提示可点击 |

### 1.3 行的底色

| 状态 | 行底色 | 行文字色 |
|---|---|---|
| 无染色 | 白 | 黑 |
| 黄色 | 浅黄 | 黑 |
| 绿色 | 浅绿 | 黑 |
| 红色 | 浅红 | 深红 |

**优先级**：手动染色 > 行选中 > 已删除 > 已修改 > 默认（互斥关系，前面样式胜出）

### 1.4 点击行为

- 点未激活色块 → 激活它（行染色）
- 点已激活色块 → 取消（行回到默认色）
- 点另一个色块 → 切换（取消旧的，激活新的）

## 二、列管理抽屉加排序

### 2.1 抽屉内每个列项

每个列项**左侧**增加一个 **8×16 像素的拖拽手柄**（三横线 ≡ 图标），鼠标悬停变手型。

```
┌─────────────────────────────────────────────┐
│ ≡  设备名称                       ✏️  🗑️    │  ← 拖拽手柄在左侧
│    text                                      │
└─────────────────────────────────────────────┘
```

### 2.2 拖拽过程视觉

- **被拖项**：半透明（透明度 0.4）+ 虚线边框
- **鼠标位置**：出现**蓝色横线**（2 像素高）指示插入位置
- **其他项**：自动下移或上移让位

### 2.3 拖拽结束

- 拖完立即**自动保存**到后端
- 保存中：手柄变**转圈加载图标**（约 0.3 秒）
- 保存失败：弹提示「排序保存失败：原因」，列项**回弹**到原位
- 保存成功：恢复正常

### 2.4 与现有功能的关系

拖拽只在**列管理抽屉**内进行，**不影响主表格**的列顺序。关闭抽屉后，主表格**重新加载**（用新顺序）。

## 三、列宽拖拽

### 3.1 拖拽区

**表头单元格右边缘内 4 像素**的范围是拖拽热区。

- 鼠标进入该区域 → 光标变成**左右箭头** + 该位置出现**2 像素蓝色竖线**
- 鼠标移出 → 恢复原光标 + 蓝线消失

```
┌──────────┬─────────────┬──────────┐
│  设备名称  │     型号     │  单价    │   ← 竖线指示可拖位置
└──────────┴─────────────┴──────────┘
        鼠标在这里
```

### 3.2 拖动过程

- **按下**：全表出现一条**半透明遮罩**（避免选中文字）+ 鼠标变 grabbing
- **拖动**：目标列**所有单元格**（表头 + 数据行）宽度同步变化，其他列不动
- 最小 60 像素 / 最大 800 像素（超出钳制）

### 3.3 抬起后

- 立即**自动保存**到后端
- 保存中：表头单元格出现**浅色加载小圈**
- 失败：弹提示，宽度**回弹**到拖动前值
- 成功：恢复正常

## 四、分页数量下拉

### 4.1 位置与外观

工具栏右侧（搜索框附近），一个**小下拉框**：

```
每页 [20 ▾]   [搜索框]
```

选项：**10 / 20 / 50 / 100 / 全部**

### 4.2 默认值

- 新建版本默认 20
- 用户切换后**立即保存**到后端（无「确定」按钮）

### 4.3 切换行为

- 选新值 → 后端保存 + 表格**重置到第 1 页** + **重新计算页数**
- 「全部」选项 → **隐藏分页器**，一次性显示所有行
- 选具体数字 → 显示分页器，按新页大小重算

### 4.4 与搜索的配合

切换分页数**不影响**搜索结果（搜索仍按当前关键词筛选），只是把筛选结果**重新分页**。

## 五、改动对现有页面的影响清单

| 位置 | 现状 | 改后 |
|---|---|---|
| 表格行首 | 只有选择框 | 选择框 + 3 色块 + 序号 |
| 工具栏右侧 | 搜索框 | 搜索框 + 分页下拉 |
| 列管理抽屉项 | 名称 + 类型 + 按钮 | 拖拽手柄 + 名称 + 类型 + 按钮 |
| 表头 | 普通 th | 普通 th + 右边缘可拖 |
| 行底色规则 | 只有 4 种固定 | 加手动染色 4 档（互斥） |

## 六、风格选择

延续现有风格：浅色背景（白/灰）、蓝色（2563eb）作为操作色、Bootstrap 风格。**不引入新色板**，不引入新字体。
