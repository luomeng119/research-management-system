## 2. 数据库迁移

### 2.1 行表加字段

```sql
ALTER TABLE generic_table_data ADD COLUMN row_color TEXT DEFAULT '';
```

兼容性：已有数据该字段为 `''`（SQLite 默认值）。

### 2.2 版本表加字段

```sql
ALTER TABLE generic_table_versions ADD COLUMN page_size INTEGER DEFAULT 20;
```

兼容性：已有数据该字段为 `20`。

在模型初始化时执行（**幂等**）：

## 3. 新增 API 设计

### 3.1 改行颜色

| 项 | 值 |
|---|---|
| 方法 | PUT |
| 路径 | `/api/generic-tables/versions/<vid>/rows/<row_key>/color` |
| 入参 | `{"row_color": "yellow"\|"green"\|"red"\|""}` |
| 校验 | 值必须在 4 选 1 内 |
| 后端操作 | `UPDATE generic_table_data SET row_color=?, updated_at=? WHERE version_id=? AND row_key=?` |
| 返回 | `{"ok":true, "row_color":"..."}` |
| 失败 | `{"error":"颜色值无效"}` 状态 400 |

### 3.2 列重排序

| 项 | 值 |
|---|---|
| 方法 | PUT |
| 路径 | `/api/generic-tables/versions/<vid>/columns/reorder` |
| 入参 | `{"order": ["col_key1", "col_key2", ...]}` |
| 校验 | order 数组长度 == 该版本当前列数；元素必须全部命中现存 col_key |
| 后端操作 | 事务内：按数组顺序为每个 col_key 赋值 col_index = 数组下标 |
| 返回 | `{"ok":true}` |
| 失败 | `{"error":"列数不匹配/存在未知列"}` 状态 400 |

### 3.3 列改宽

| 项 | 值 |
|---|---|
| 方法 | PUT |
| 路径 | `/api/generic-tables/versions/<vid>/columns/<col_key>/width` |
| 入参 | `{"col_width": 200}` |
| 校验 | 60 ≤ col_width ≤ 800 |
| 后端操作 | `UPDATE generic_table_columns SET col_width=? WHERE version_id=? AND col_key=?` |
| 返回 | `{"ok":true, "col_width":200}` |
| 失败 | `{"error":"宽度需在 60-800 之间"}` 状态 400 |

### 3.4 改分页数

| 项 | 值 |
|---|---|
| 方法 | PUT |
| 路径 | `/api/generic-tables/versions/<vid>/page-size` |
| 入参 | `{"page_size": 20\|50\|100\|-1}` |
| 校验 | 值在 `{-1, 10, 20, 50, 100}` 内 |
| 后端操作 | `UPDATE generic_table_versions SET page_size=? WHERE version_id=?` |
| 返回 | `{"ok":true, "page_size":20}` |
| 失败 | `{"error":"分页数无效"}` 状态 400 |

## 4. 前端交互设计

### 4.1 行 3 色块

**HTML 结构**（在每行第 1 个 td 之后、序号 td 之前插入）：

```html
<td class="color-cells">
  <span class="color-chip" data-color="yellow" title="注意"></span>
  <span class="color-chip" data-color="green" title="确认"></span>
  <span class="color-chip" data-color="red" title="警告"></span>
</td>
```

**CSS 关键样式**：
- 色块：14×14 像素，圆角，inline-block
- 黄色：`#fde68a`，绿色：`#bbf7d0`，红色：`#fecaca`
- 激活态：`outline: 2px solid #374151; outline-offset: 1px;`
- 悬停：`transform: scale(1.1);` + 鼠标变手型
- 行底色优先级（行 className 顺序）：`row-color-{{row_color}}` > `row-selected` > `row-deleted` > `row-modified` > 默认
- 行底色 CSS：
  - `.row-color-yellow { background: #fef3c7; }`
  - `.row-color-green { background: #d1fae5; }`
  - `.row-color-red { background: #fee2e2; color: #991b1b; }`

**JS 逻辑**：
- 事件委托：监听 `color-cells` 容器的 click
- 从 `event.target.dataset.color` 取色
- 调 API（带 r.ok 校验，catch err）
- 成功 → 改 tr 的 className + 色块自身 outline
- 失败 → alert(err.message) + 不改 UI

### 4.2 列管理拖拽

**HTML 结构**（在每个 col-item 内部最前面加）：

```html
<span class="drag-handle" title="拖动排序">≡</span>
```

**CSS 关键样式**：
- 拖拽手柄：cursor: grab，padding: 0 8px，颜色 #6b7280
- 拖动中（.dragging）：opacity 0.4，cursor: grabbing
- 插入线（.drop-indicator）：2 像素高，背景 #2563eb，绝对定位

**JS 逻辑（HTML5 拖拽 API）**：
- 给 `.col-item` 加 `draggable="true"`
- `dragstart`：保存被拖 col_key，给被拖项加 .dragging class
- `dragover`（e.preventDefault）：计算鼠标 Y 位置 → 在拖动路径上找最近兄弟 → 显示/移动 .drop-indicator
- `dragend`：先清掉 .drop-indicator 和 .dragging → 从 DOM 重排 col-item → 调 API
- API 失败：alert + location.reload() 回退

### 4.3 表头列宽拖拽

**HTML 结构**：在每个 th 内部**最右**插入一个拖拽热区：

```html
<th>
  列名
  <span class="resize-handle" data-col-key="..."></span>
</th>
```

**CSS 关键样式**：
- 拖拽手柄：position absolute，right 0，top 0，bottom 0，width 4px，cursor col-resize
- 悬停：背景 #2563eb（蓝线）
- 拖动中：body 加 .resizing 类（cursor col-resize + 禁止选中文本）

**JS 逻辑**：
- `mousedown` 在 .resize-handle 上：记下 col_key、起始 X、起始 width
- `mousemove`（document 级）：计算新 width = 起始 width + 移动 X，钳制 60-800 → 改该列所有 td/th 的 width
- `mouseup`（document 级）：解绑 mousemove/mouseup + 调 API
- API 失败：alert + location.reload() 回退

### 4.4 分页下拉

**HTML 结构**（在工具栏搜索框前加）：

```html
<select class="form-select form-select-sm" id="pageSizeSelect" style="width:100px;">
  <option value="10">每页 10</option>
  <option value="20">每页 20</option>
  <option value="50">每页 50</option>
  <option value="100">每页 100</option>
  <option value="-1">全部</option>
</select>
```

**JS 逻辑**：
- 页面加载时：根据后端传来的 page_size 设置 select.value
- `change` 事件：调 API + 成功后 currentPage=1 + renderTable()
- 「全部」（-1）：PAGE_SIZE = ROWS.length（或 Infinity）→ 一次性渲染
- API 失败：alert + select.value 回到原值

## 8. 风险评估

| 风险 | 等级 | 兜底 |
|---|---|---|
| ALTER TABLE 失败 | 低 | try/except 兜底 |
| 拖拽和现有 col-item 编辑按钮冲突 | 低 | 手柄和按钮分区，按钮 stopPropagation |
| 列宽拖动触发 cell-edit | 低 | 拖动中加 .resizing class，禁用 cell 的 click |
| Playwright 拖拽不稳定 | 中 | 用 dispatchEvent 模拟 HTML5 拖拽事件 |
| 离线包需要新加 SortableJS | 不适用 | 已决定用原生 API，无新依赖 |
