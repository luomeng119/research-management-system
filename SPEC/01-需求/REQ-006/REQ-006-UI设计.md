# REQ-006 UI设计方案：报销项一键生成完整报销单

## 页面结构

### records.html — 报销项详情页（修改）

本需求为现有页面局部修改，不改变整体布局，仅在报销项操作区新增一个按钮。

### 按钮区域布局（ASCII）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  📋 单据列表                                          │                       │
│  ┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐   │
│  │ <i class="bi bi-plus-circle"></i> 新建单据 │ │ <i class="bi bi-printer"></i> 汇总打印 │ │ <i class="bi bi-file-earmark-word"></i> 生成报销单 │ │
│  └─────────────────────┘ └─────────────────────┘ └─────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────────┘
```

说明：
- 「生成报销单」按钮新增于「汇总打印」右侧，三按钮并排
- 按钮样式：`btn btn-sm btn-outline-primary py-0`
- 使用 Bootstrap 图标：`bi-file-earmark-word`
- 点击行为：调用 `generateReport(${rid})`，与 `mergePrintDocs(${rid})` 并列

### 前端交互流程

```
用户点击「生成报销单」
       ↓
按钮显示 loading 状态（spinner）
       ↓
POST /expense/documents/api/reimbursements/{rid}/generate_report
       ↓
成功：下载 .docx 文件 + 弹出提示「报销单已生成」
失败：alert 提示「生成失败: {error}」
       ↓
按钮恢复正常状态
```

### 按钮状态

| 状态 | 表现 |
|------|------|
| 默认 | `<i class="bi bi-file-earmark-word"></i> 生成报销单`，绿色 outline |
| 加载中 | spinner + `生成中...`，按钮禁用 |
| 失败 | 恢复默认状态，alert 弹窗提示 |
