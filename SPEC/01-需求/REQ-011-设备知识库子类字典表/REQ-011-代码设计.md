## 6. 列表页代码设计

### 6.1 路由（equipment.py 约22行）

```python
# 获取所有子类（按分类分组）
sc_model = KnowledgeSubclassModel()
all_subclasses = sc_model.get_all()
subclasses_json = {}
for sc in all_subclasses:
    cat = sc.get('parent_category', '')
    if cat not in subclasses_json:
        subclasses_json[cat] = []
    subclasses_json[cat].append({'subclass_name': sc.get('subclass_name', '')})

return render_template('equipment/index.html',
```

### 6.3 JS联动

```javascript
const subclassData = {{ subclasses_json | tojson }};

function updateSubclassOptions() {
    const category = document.getElementById('categoryFilter').value;
    const subclassSelect = document.getElementById('subclassFilter');
    subclassSelect.innerHTML = '<option value="">全部子类</option>';
    if (!category || !subclassData[category]) return;
    subclassData[category].forEach(sc => {
        const opt = document.createElement('option');
        opt.value = sc.subclass_name;
        opt.textContent = sc.subclass_name;
        subclassSelect.appendChild(opt);
    });
}
```
