## UI 1: 列表页筛选器（REQ-011-11）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 设备知识库管理                    [ + 新增设备 ]          共 N 条记录        │
├──────────────────────────────────────────────────────────────────────────────┤
│ 全部分类    装备子类       全部形态    全部状态     [综合搜索设备...]  [筛选] │
│    ↓            ↓                                                        [重置]│
│ <select>   <select>                                                     │
│            (根据分类动态加载选项)                                          │
├──────────────────────────────────────────────────────────────────────────────┤
│ 设备编号 │ 设备名称         │ 分类        │ 设备子类 │ 形态  │ 技术状态 │ 操作 │
│ EQP...   │ 密码机V3        │ 密码设备    │ 密码机   │ 固定式│ 已定型   │ ...  │
│ EQP...   │ 防火墙          │ 安全设备    │ 防火墙   │ 固定式│ 已定型   │ ...  │
└──────────────────────────────────────────────────────────────────────────────┘
```

**说明**：
- 分类与子类联动：切换分类后子类下拉自动刷新为该分类下的子类选项
- 分类选项：全部分类 / 密码设备 / 安全设备 / 通用设备 / 其他设备
- 子类下拉初始显示"全部子类"，根据所选分类动态加载选项

## UI 2: 导入步骤2映射表（REQ-011-3 + REQ-011-4）

```
┌────────────────────────────────────────────────────────────────────────────────┐
│ 设备导入 - 数据映射与确认                                              [取消] │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│  检测到 N 条数据，请确认字段映射关系：                                        │
│                                                                                │
│  ┌─────────────┬────────────────┬─────────────────┬────────────────────────┐  │
│  │ Excel 列    │ 目标字段       │ 匹配状态        │ 操作                  │  │
│  ├─────────────┼────────────────┼─────────────────┼────────────────────────┤  │
│  │ 设备名称    │ 设备名称       │ ✓ 精确匹配      │                       │  │
│  │ 分类        │ 分类           │ ✓ 精确匹配      │                       │  │
│  │ 设备子类    │ 设备子类       │ 传输设备(绿色)  │                       │  │
│  │            │                │ 传输设(黄色)    │                       │  │
│  │            │                │ 加密计算模块    │ [确认] [跳过]        │  │
│  │            │                │ -(灰色)         │                       │  │
│  │ 形态        │ 形态           │ ✓ 精确匹配      │                       │  │
│  └─────────────┴────────────────┴─────────────────┴────────────────────────┘  │
│                                                                                │
│                              [上一步]         [下一步]                         │
└────────────────────────────────────────────────────────────────────────────────┘
```

**颜色标注说明**：
- 绿色 `#22c55e` — 精确匹配
- 黄色 `#eab308` — 模糊匹配（显示匹配到的标准名）
- 橙色 `#f97316` — 待新增（显示原始值，附确认/跳过按钮）
- 灰色 `#9ca3af` — 空值（显示 `-`）
- **不使用圆形图标**，字段文本直接用颜色指示

**集中确认框**（点「下一步」后弹出）：
