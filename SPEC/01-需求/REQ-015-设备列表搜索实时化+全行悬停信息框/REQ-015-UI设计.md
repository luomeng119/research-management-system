## UI 2：自定义行 tooltip

### 2.1 tooltip 样式

```
┌──────────────────────────────┐
│ 设备名称:  密码机V3          │ ← 12px 黑底 #1a1a2e + 浅色文字
│ 型号:      X-3               │    圆角 6px + 阴影 0 4px 12px rgba(0,0,0,0.3)
│ 曾用名:    加密终端A         │    padding 10px 14px
│ 分类:      密码设备          │    max-width 400px
│ 设备子类:  密码机            │    line-height 1.6
│ 形态:      固定式            │    字体 Microsoft YaHei 12px
│ 单价:      12.5 万元         │
│ 技术状态:  已定型            │ ← 字段缺失显示 "-"，不隐藏
│ 研制单位:  中国电子科技集团第14研究所、北京理工大学
│ 主要用途:  用于XX场景XX功能
│ 功能技术指标: 支持XX协议
│ 加装要求:  需配合XX模块使用
│ 资源保障:  功耗XX瓦
└──────────────────────────────┘
  ↑ 鼠标位置
  ↑
  偏移 (+15, +15) 避免遮挡
```

**配色**：
- 背景：`#1a1a2e`（深蓝黑）
- 文字：主标签 `#9a9acc`（浅紫灰），值 `#e0e0e0`（白）
- 边框：`1px solid #2a2a4a`
- 阴影：`0 4px 12px rgba(0,0,0,0.3)`
- 显示/隐藏动画：fade-in 100ms / fade-out 100ms

### 2.2 触发与消失

```
   鼠标进入 tr ──200ms──→  显示 tooltip（跟随鼠标 +15,+15）
   鼠标移动           →  实时更新 tooltip 位置
   鼠标离开 tr         →  fade-out 100ms 隐藏
   鼠标进入其他 tr     →  切换显示新行的 tooltip
   页面滚动 / resize   →  立即隐藏
   鼠标移出 tbody      →  fade-out 100ms 隐藏
```

**关键设计**：
- 200ms 延迟：避免鼠标快速划过时频繁显示
- 跟随鼠标：用户拖动时 tooltip 内容不卡顿
- 边界保护：tooltip 右边超出视口 → 改为左侧显示（`+15 → -tooltip.width - 15`）

### 2.3 跨 td 悬停行为对比

| 鼠标位置 | 当前行为 | 修复后行为 |
|----------|----------|-----------|
| 「设备名称」td | ❌ 单字段 title（20字截断）| ✅ 完整 12 字段 tooltip |
| 「型号」td | ✅ 完整行 title | ✅ 完整 12 字段 tooltip |
| 「分类」td | ❌ 单字段 title | ✅ 完整 12 字段 tooltip |
| 「操作」列（👁）| ✅ 完整行 title | ✅ 完整 12 字段 tooltip（点 👁 仍正常跳转） |
| 「操作」列（🗑）| ✅ 完整行 title | ✅ 完整 12 字段 tooltip（点 🗑 仍弹确认） |
| 表头 `<th>` | 无 tooltip | 无 tooltip（数据行才显示） |
| 「暂无设备」空态 | 无 tooltip | 无 tooltip（无数据行） |

## UI 3：错误条样式

```
┌────────────────────────────────────────────────────┐
│ ⚠️ 检索失败：网络异常（HTTP 500）。点击重试  [×]  │ ← 红色 #f8d7da 背景
└────────────────────────────────────────────────────┘
```

- 位置：搜索框下方，表格上方
- 颜色：`#f8d7da` 背景 + `#721c24` 文字 + `#f5c6cb` 边框
- 操作：
  - 「点击重试」→ 重新发请求
  - 「×」→ 关闭错误条
- 5 秒后自动消失（避免长期占位）

## UI 4：URL 同步

```
初始:    http://192.168.1.6:5188/equipment
         ↓ 用户输入"密码"
         ↓ 300ms 后
         ↓ history.replaceState
实时:    http://192.168.1.6:5188/equipment?keyword=%E5%AF%86%E7%A0%81&category=%E5%AE%89%E5%85%A8%E8%AE%BE%E5%A4%87
```

**说明**：URL 含完整状态（keyword + category + form + tech_status + subclass + page），**F5 刷新不丢**。但用 `replaceState` 而非 `pushState`——避免污染浏览器历史栈（用户点返回不会一步步回退到无 keyword 的状态）。
