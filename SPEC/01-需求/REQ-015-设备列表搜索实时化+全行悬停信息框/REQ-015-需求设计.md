# REQ-015 需求设计

**状态：阶段二（需求设计）— 待确认**

---

## 1. 用户描述复述

> "设备知识库列表页（4 个分类）优化两个功能：① 综合搜索框增加实时响应（输入即检索）；② 鼠标悬停全行统一弹完整信息框。"

---

## 2. 功能理解

### 2.1 实时搜索
- **本质**：把"输入→点按钮"的两步操作，压缩为"输入即检索"的一步操作
- **核心价值**：列表页 4 大类数据常达 4900+ 行（实测 4902），用户搜 1~3 个关键字时体验差距大
- **触发时机**：输入框内容变化 + debounce 300ms
- **保留能力**：手动按「筛选」按钮 / Enter 键仍可触发（向后兼容）

### 2.2 全行悬停信息框
- **本质**：用 JS 实现的统一 tooltip，**整行任意位置**悬停都展示该行的完整字段集
- **当前问题**：HTML 原生 `title` 的事件冒泡规则——td 自身有 `title` 时优先用 td 的（显示单字段 20 字截断版），无 title 的 td 才继承 tr 的（显示完整行信息）
- **修复方向**：移除所有 `<td title>`，tr 上挂 data-tooltip-html，JS 监听 mouseenter 显示自定义 tooltip 元素

## 5. 流程

### 5.1 实时搜索流程
```
用户在 keyword input 输入字符
    ↓
触发 input 事件
    ↓
debounce 300ms
    ↓
fetch('/equipment?' + queryString + '&fragment=1')
    ↓ (后端若支持 fragment=1 返回纯表格 HTML；否则后端渲染整页，前端用 jQuery 提取 #equipmentTableWrap)
    ↓
替换 #equipmentTableWrap.innerHTML
    ↓
history.replaceState 更新 URL
    ↓
绑定新行 mouseenter/leave → 显示 tooltip
```

### 5.2 悬停 tooltip 流程
```
鼠标进入 tbody 任一 <tr>
    ↓
事件委托处理：读取 tr.dataset.tooltipHtml
    ↓
构造 #rowTooltip 内容（按 \n 分行，每行 "标签: 值"）
    ↓
定位到鼠标位置 + 偏移 (15, 15)
    ↓
显示 tooltip（fade-in 100ms）
    ↓
鼠标移动时实时更新位置
    ↓
鼠标离开 tr / 表格时 fade-out 隐藏
    ↓
页面滚动 / 窗口 resize 时隐藏
```

## 6. 场景

| 场景 | 期望 |
|------|------|
| 打开 `/equipment`，输入"密码" | 300ms 后表格自动刷新为含"密码"关键字的设备，URL 变 `?keyword=密码` |
| 选中"安全设备"分类 + 输入"XX" | 联动筛选：300ms 后只展示安全设备类下含"XX"的 |
| 刷新带 `?keyword=密码` 的 URL | 页面加载后表格自动展示匹配结果（前后端都用 keyword 参数） |
| 鼠标移到任一 tr 任一 td | 弹出含全部 12 个字段的 tooltip |
| 鼠标移到"操作"列（眼睛/铅笔/垃圾桶按钮） | 弹 tooltip，但点按钮仍能正常跳转/弹确认 |
| 输入"密码" → 立即删空 → 立即输入"通用" | debounce 期间旧请求被忽略，只发最后 1 个 |
| 网络慢/失败 | 显示错误提示，不卡死 UI |

## 7. 数据流

**前端发请求**：
```
GET /equipment?keyword=密码&category=安全设备&form=&tech_status=&subclass=&page=1
```

**后端现有逻辑**（routes/equipment.py::index）：
- 接收 query 参数
- 走同款 SQL 查询（已支持 keyword 模糊匹配 `name` / `model`）
- 渲染 `equipment/index.html` 返回整页

**前端处理响应**：
- 方案 A：后端加 `?fragment=1` 返回纯表格片段
- 方案 B：前端用 DOMParser 解析整页 HTML，提取 `#equipmentTableWrap` 容器

> **倾向方案 A**（更轻量、更明确、避免渲染其他无关区域），如需改后端在代码设计阶段确认。

## 8. 验收标准

1. 输入"密码"→ 300~500ms 内表格自动更新（无手动点按钮）
2. URL 实时同步 keyword 参数，刷新页面结果保留
3. Enter 键 / 重置按钮仍工作
4. 4 个分类（安全/密码/通用/其他）都生效
5. 表格**任意单元格**（含"操作"列）悬停都弹完整信息框
6. tooltip 含全部 12 个字段（设备名称/型号/曾用名/分类/子类/形态/单价/技术状态/研制单位/主要用途/功能技术指标/加装要求/资源保障）
7. tooltip 不被表格边界截断、不残留、不闪烁
8. 移动端（窄屏）tooltip 不溢出视口
9. 已有功能（详情/编辑/删除按钮）不受影响
10. 网络失败时不卡死 UI
