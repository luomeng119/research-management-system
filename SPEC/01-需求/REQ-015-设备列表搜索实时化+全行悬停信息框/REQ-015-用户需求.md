## 用户原始描述

设备知识库列表页（含安全设备 / 密码设备 / 通用设备 / 其他设备）优化两点：

1. **综合搜索框实时响应**：用户输入字符后即时执行检索，不需要再点「筛选」按钮（"这个功能之前做过要求"——经查历史未发现已实现记录，按用户当前描述视为新增需求）。
2. **鼠标悬停信息框统一**：目前仅特定区域（无 `title` 的 td）悬停弹出完整行信息；带 `title` 的 td 悬停只显示单个字段值。要求**整行任意位置悬停都弹出完整信息框**。

## 关键约束

1. **搜索实时性**：必须 debounce 300~500ms 避免每键击都发请求；保留手动点击「筛选」按钮的能力（兼容回车/重置）
2. **局部刷新**：AJAX 替换表格 + 分页，URL 同步 `?keyword=xxx`（用 history.replaceState 保持刷新可恢复）
3. **后端零改动**：复用现有 `/equipment` 路由，参数 keyword 已支持
4. **悬停体验**：替换 HTML 原生 `title` 为 Bootstrap tooltip / 自定义 div tooltip，支持富文本（多行键值对）、长文本换行
5. **统一范围**：整行任意 td 悬停都触发**同一个完整信息框**（不再"特定区域 vs 单字段"二分化）
6. **不破坏现有功能**：保留 tr 鼠标右键 / 选中复制等浏览器原生行为
