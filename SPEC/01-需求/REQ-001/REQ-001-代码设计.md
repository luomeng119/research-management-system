```sql
ALTER TABLE expense_reimbursement ADD COLUMN reimbursement_type TEXT DEFAULT '采购报销';
```

### 1.2 expense_payment 表

```sql
ALTER TABLE expense_payment ADD COLUMN payer TEXT DEFAULT '';
```

### 1.3 expense_invoice 表（已有 content，新增 spec）

```sql
ALTER TABLE expense_invoice ADD COLUMN spec TEXT DEFAULT '';
```

## 二、OCR 变更

### 2.1 recognize_payment() 扩展

新增提取 `payer`（收款方/商户名）：

```python
# 搜索模式：
r'收款人[：:]\s*([^\n]+)'
r'商户名称[：:]\s*([^\n]+)'
r'交易对方[：:]\s*([^\n]+)'
```

### 2.2 发票商品明细 spec 提取

`add_invoice()` 调用处增加 `spec` 参数（传入 `items[0].spec`）。

## 三、API 变更

### 3.1 新增报销类型字段

| API | 变更 |
|-----|------|
| GET /api/reimbursements | 返回列表每项含 reimbursement_type |
| POST /api/reimbursements | 请求体支持 reimbursement_type，默认"采购报销" |
| PUT /api/reimbursements/\<id\> | 请求体支持 reimbursement_type 变更（草稿→可改，已确认→不可改） |

### 3.2 报销项详情 API 增强

GET `/api/reimbursements/<id>` 的 invoices/payments 返回增强：

- invoices: 新增 spec 字段
- payments: 新增 payer 字段

### 3.3 自动匹配逻辑修改

```python
TRAVEL_TYPES = {'火车票', '航空行程单', '出租车发票', '网约车'}
# 匹配成功后：
reimb_type = '出差报销' if invoice_type in TRAVEL_TYPES else '采购报销'
update_reimbursement(reimb_id, reimbursement_type=reimb_type)
```

```html
<!-- 操作列新增（草稿状态显示，已确认状态隐藏） -->
```
