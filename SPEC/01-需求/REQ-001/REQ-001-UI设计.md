## 二、"从待整理记录中选择"弹窗（新增布局）

### 2.1 弹窗结构

```
┌─────────────────────────────────────────────────┐
│  从待整理记录中选择                         [X] │
├─────────────────────────────────────────────────┤
│  [报销类型：出差报销 ○  采购报销 ●]            │  ← 报销类型选择
├─────────────────────────────────────────────────┤
│  📄 待整理发票                    共 N 条      │
│  ┌───────────────────────────────────────────┐ │
│  │ ☐ 发票号      销售方        金额     日期  │ │
│  │ ☐ 12345678   上海宝钢    ¥440.88  04-17 │ │
│  │ ...                                            │
│  └───────────────────────────────────────────┘ │
│                                                 │
│  💳 待整理支付记录                共 M 条      │
│  ┌───────────────────────────────────────────┐ │
│  │ ☐ 凭证号    收款方      金额     日期      │ │
│  │ ☐ 98765     京东商城    ¥440.88  04-10  │ │
│  │ ...                                            │
│  └───────────────────────────────────────────┘ │
│                                                 │
│                            已选: 0 项  [取消][确定]│
└─────────────────────────────────────────────────┘
```

### 2.2 关键 UI 决策

**决策：发票列表和支付记录列表上下排列，不使用 Tab 切换**

原因：减少操作步骤，两个列表可同时对比参考；报销类型单选按钮放在列表上方，方便先选类型再选记录。

### 2.3 各列展示内容

#### 待整理发票列表

| 列 | 数据来源 | 说明 |
|----|---------|------|
| 复选框 | - | 选择发票 |
| 发票号 | invoice_no | |
| 销售方 | seller | 即"交易场所" |
| 内容 | items[0].name + items[0].spec | **项目名称+规格型号**（来自 OCR） |
| 金额 | amount | 金额，黄色高亮 |
| 日期 | date | 发票日期 |

#### 待整理支付记录列表

| 列 | 数据来源 | 说明 |
|----|---------|------|
| 复选框 | - | 选择支付记录 |
| 凭证号 | payment_no | |
| 收款方 | payer（新增字段） | 从 OCR 提取的商户名/收款方 |
| 金额 | amount | 金额，黄色高亮 |
| 日期 | pay_date | 支付日期 |

### 2.4 报销类型选择

- 单选按钮组：出差报销 / 采购报销
- 默认选中：采购报销
- 位置：弹窗标题下方，列表上方
- 作用：创建报销项时预设类型；或在"新增报销项"流程中直接指定

## 四、报销项详情展开区（不变）

位置：报销项行下方展开区域

### 4.1 发票明细表

| 列 | 数据来源 |
|----|---------|
| 发票号 | invoice_no |
| 日期 | date |
| 金额 | amount |
| 销售方 | seller |
| 内容 | items[0].name + items[0].spec（如 "钢材 10mm"） |
| 操作 | 移除按钮 |

### 4.2 支付记录表

| 列 | 数据来源 |
|----|---------|
| 凭证号 | payment_no |
| 日期 | pay_date |
| 金额 | amount |
| 收款方 | payer |
| 内容 | payer 或 "-" |
| 操作 | 移除按钮 |

## 五、待整理发票区（不变）

位置：报销项列表下方，两个独立卡片

### 5.1 待整理发票卡片

表头：销售方 | 金额 | 日期 | 发票号 | **内容（品名+规格）** | 操作

注：原"文件名"列改为"内容"，显示 items[0].name+spec 或 seller

### 5.2 待整理支付记录卡片

表头：收款方 | 金额 | 日期 | 凭证号 | **收款方** | 操作

注：第1列"收款方"修复（原来显示 "-" 因为 payer 字段不存在）；第5列显示收款方
