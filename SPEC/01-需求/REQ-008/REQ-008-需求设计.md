# REQ-008 宿主设备管理 — 需求设计

状态：阶段二（需求设计）— 已确认

---

## 一、功能理解

宿主设备是密码设备的配套硬件，与密码设备之间是多对多关联关系。例如：一台密码设备可能需要多台宿主设备提供计算/通信支撑；一台宿主设备也可能同时为多台密码设备服务。

系统需要提供宿主设备的独立管理能力，以及与密码设备之间的双向关联管理。

---

## 二、子需求拆解

### REQ-008-A 宿主设备数据表

新建 `host_devices` 表，包含以下字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| host_id | TEXT | 主键，格式 HD+时间戳，如 HD20260519120000 |
| name | TEXT | 名称（非空） |
| model | TEXT | 型号 |
| category | TEXT | 类型（来自 host_device_categories 表） |
| form | TEXT | 形态（下拉：独立式 / 板卡式） |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |

### REQ-008-B 类型管理（宿主设备类型）

新建 `host_device_categories` 表：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 自增主键 |
| name | TEXT | 类型名称（非空，唯一） |
| created_at | TEXT | 创建时间 |

默认类型：通信电台、计算存储、数据链

**类型合并修改**：用户可在类型管理页面将类型 A 合并到类型 B，系统将 `host_devices.category` 中所有 A 更新为 B。

### REQ-008-C 宿主设备列表页

独立入口 `/equipment/hosts`，功能与现有设备列表类似：

- 按类型、形态筛选
- 关键词搜索（名称/型号）
- 分页展示
- 添加 / 编辑 / 删除宿主设备
- 导出 Excel

### REQ-008-D 宿主设备详情页

`/equipment/hosts/detail/<host_id>`，展示宿主设备完整信息及关联的密码设备列表。

### REQ-008-E 密码设备详情页增加关联宿主设备管理

在现有密码设备详情页增加「关联宿主设备」区块，支持：

- 查看已关联的宿主设备列表
- 添加关联（从宿主设备库选择）
- 移除关联
- 跳转到宿主设备详情页

### REQ-008-F 宿主设备详情页增加关联密码设备管理

在宿主设备详情页增加「关联密码设备」区块，支持：

- 查看已关联的密码设备列表
- 添加关联（从密码设备库选择）
- 移除关联
- 跳转到密码设备详情页

### REQ-008-G 关联中间表

新建 `device_host_relations` 表：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 自增主键 |
| device_id | TEXT | 密码设备 ID（外键 → equipment.equipment_id） |
| host_id | TEXT | 宿主设备 ID（外键 → host_devices.host_id） |
| created_at | TEXT | 关联创建时间 |

唯一约束：(device_id, host_id) 防止重复关联。

## 四、流程描述

### 添加宿主设备流程

用户进入 `/equipment/hosts` → 点击「添加宿主设备」→ 填写表单（名称/型号/类型/形态）→ 提交 → 创建记录 → 返回列表页

### 关联设备流程

在密码设备详情页点击「添加关联宿主设备」→ 弹出宿主设备选择框（可搜索、分页）→ 选择宿主设备 → 确认 → 创建关联记录 → 刷新关联列表

### 类型合并流程

管理员进入类型管理页面 → 选择源类型 → 选择目标类型 → 确认合并 → 系统更新所有相关宿主设备的 category 字段 → 源类型记录删除

---

## 五、数据流向

```
宿主设备表 (host_devices)
       ↑
    device_host_relations（中间表，多对多）
       ↓
密码设备表 (equipment)
```

---

## 六、边界与异常

- 关联时若设备或宿主设备已被删除，关联记录同步删除（或置空外键）
- 删除宿主设备时级联删除关联记录
- 删除密码设备时级联删除关联记录
- 同一对 (device_id, host_id) 不可重复关联
