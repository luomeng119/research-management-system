## 一、数据库变更

### 新建表：host_devices（宿主设备主表）

```sql
CREATE TABLE host_devices (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    host_id TEXT UNIQUE NOT NULL,   -- HD+时间戳
    name TEXT NOT NULL,
    model TEXT,
    category TEXT,
    form TEXT,
    created_at TEXT,
    updated_at TEXT
);
```

### 新建表：host_device_categories（类型表）

```sql
CREATE TABLE host_device_categories (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT UNIQUE NOT NULL,
    created_at TEXT
);
```

### 新建表：device_host_relations（关联中间表）

```sql
CREATE TABLE device_host_relations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id TEXT NOT NULL,
    host_id TEXT NOT NULL,
    quantity INTEGER DEFAULT 1,     -- 数量：宿主设备加装密码设备的台数
    created_at TEXT,
    updated_at TEXT,
    UNIQUE(device_id, host_id)
);
```

> 注：quantity 仅在「宿主设备→密码设备」方向有意义（加装数量）；「密码设备→宿主设备」方向通过查询同一中间表反向获取，无需单独字段。

### 新增 equipment 表字段（可选）

无需修改 equipment 表，关联关系完全通过中间表实现。

## 五、关键实现细节

### 类型合并实现

用户选择将「通信电台」合并到「计算存储」：
1. 执行 `UPDATE host_devices SET category='计算存储' WHERE category='通信电台'`
2. 删除 `host_device_categories` 中 name='通信电台' 的记录

### 关联选择模态框

- 复用 `_relation_modal.html` 模板
- 通过 API 获取可选设备列表，支持分页和搜索
- 选择后通过 `/equipment/api/hosts` POST 创建关联

### 级联删除

- 删除宿主设备前，先调用 `DeviceHostRelationModel.delete_by_host(host_id)` 清除关联
- 删除密码设备前，同理清理 `device_host_relations`

### 列表页分页

沿用现有 equipment 列表页的分页逻辑，使用 page/per_page 参数。
