```

│ 选择关联设备                                                               [×]           │
├──────────────────────────────────────────────────────────────────────────────────────┤
│ 已选择设备                                                                             │
│ ┌──────────────────────────────────────────────────────────────────────────────────┐  │
│ │ 设备名称     │ 型号    │ 分类      │ 数量   │ 操作                                    │  │
│ │ 密码机Y      │ PK-200  │ 密码设备  │ [2] [×]│                                         │  │
│ └──────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                       │
│ [全部分类 ▼] [________ 搜索设备名称/型号 ________] [搜索]                               │
│                                                                                       │
│ ┌──────────────────────────────────────────────────────────────────────────────────┐  │
│ │ ☐ 密码机X    │ RT-900  │ 密码设备  │ 已定型       │ 数量：[1]                   │  │
│ │ ☑ 密码机Y    │ PK-200  │ 密码设备  │ 研制中       │ 数量：[2]                   │  │
│ │ ☐ 安全设备A  │ SG-100  │ 安全设备  │ 运行中       │ 数量：[1]                   │  │
│ │ ☐ 通用主机Z  │ GH-300  │ 通用设备  │ 已定型       │ 数量：[1]                   │  │
│ └──────────────────────────────────────────────────────────────────────────────────┘  │
│ [< 上一页]                                              第 1/5 页  [下一页 >]          │

│                                                           [取消]  [确认关联(1项)]     │

```
**设计说明：**
- **上半部分：已选择设备列表** — 显示设备名称/型号/分类/数量，数量可修改，点击 × 移除；编辑场景自动回显已有关联设备
- **分类下拉：** `全部` / `安全设备` / `密码设备` / `通用设备` / `其他设备`
- **搜索：** 按名称或型号模糊匹配，搜索后列表刷新
- **可选设备列表：** 复选框选中，分类列明确显示设备类型，数量输入框默认 1，选中后才可编辑
- **确认按钮：** 显示已选数量，批量写入关联关系

## UI-6：类型管理页面 `/equipment/hosts/categories`

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 宿主设备类型管理                                                                │
├────────────────────────────────────────────────────────────────────────────┤
│  类型名称              │ 创建时间       │ 操作                                │
│  通信电台              │ 2026-05-19    │ [合并到 ▼] [删除]                  │
│  计算存储              │ 2026-05-19    │ [合并到 ▼] [删除]                  │
│  数据链                │ 2026-05-19    │ [合并到 ▼] [删除]                  │
│                                                                             │
│  [__________________] [+ 新增类型]                                           │
└────────────────────────────────────────────────────────────────────────────┘
```

**操作行为：**
- **合并到**：下拉框选中后立即执行，数据迁移到目标类型，删除源类型记录
- **删除**：有关联设备的类型显示为灰色不可点击，无关联设备的类型可删除
- **新增类型**：行内输入框，填写后点击 [+ 新增类型] 写入数据库
