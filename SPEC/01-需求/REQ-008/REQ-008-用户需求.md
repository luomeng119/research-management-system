# REQ-008 宿主设备管理

状态：阶段一（用户需求）— 已确认

---

## 用户需求（原始描述）

> 新增「宿主设备」功能，作为设备知识库的子分类。宿主设备是密码设备的配套设备，与密码设备之间是多对多关系（可正向关联，也可反向关联）。
>
> 宿主设备字段：类型（默认：通信电台/计算存储/数据链，支持自定义，支持类型合并修改）、型号、名称、形态（独立式/板卡式）。

## 确认记录

| 问题 | 答案 |
|------|------|
| 数据结构 | 宿主设备是独立的表 |
| 关联关系 | 密码设备 ←→ 宿主设备，多对多，通过中间表 |
| 正向/反向关联 | 密码设备详情页看宿主设备，宿主设备详情页看密码设备 |
| 类型合并修改 | 用户更改类型名称时同步更新数据库所有相关记录 |
| 形态 | 下拉选择（独立式 / 板卡式） |
| 独立列表页 | 需要 `/equipment/hosts` 独立入口 |
| 现有数据迁移 | 无需迁移 |
