## 一、数据库变更

```sql
-- expense_reimbursement 表新增 is_paid 字段
ALTER TABLE expense_reimbursement ADD COLUMN is_paid INTEGER DEFAULT 0;
```

**说明：**
- `is_paid`: 0=未报销，1=已报销
- 现有 `status` 列保留，历史数据兼容
- 新增报销项时 `is_paid` 默认为 0

## 四、SQL 变更详解

### get_all_reimbursements 查询重构

```sql
SELECT r.*,
    COALESCE(r.is_paid, 0) AS is_paid,
    (
        SELECT MAX(dt) FROM (
            SELECT MAX(i.date) AS dt FROM expense_invoice i WHERE i.reimbursement_id = r.id
            UNION ALL
            SELECT MAX(p.pay_date) AS dt FROM expense_payment p WHERE p.reimbursement_id = r.id
        )
    ) AS payment_time,
    (SELECT COUNT(*) FROM expense_invoice WHERE reimbursement_id=r.id) AS invoice_count,
    (SELECT COUNT(*) FROM expense_payment WHERE reimbursement_id=r.id) AS payment_count
FROM expense_reimbursement r
...
```

## 五、边界处理

| 场景 | 处理方式 |
|------|---------|
| 报销项无关联记录 | `payment_time` 返回 `null`，前端显示 "—" |
| `is_paid` 为 NULL | 前端用 `COALESCE(is_paid, 0)` 视为"未报销" |
| 标题编辑为空 | 前端阻止保存；若请求到达后端，还原原标题 |
| hover 卡片定位越界 | 复用 `list_preview_helper.html` 已有边界检测逻辑 |
