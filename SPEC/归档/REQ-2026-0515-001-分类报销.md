## 需求描述

目前报销助手没有区分报销类型，统一进行发票上传、自动/手动匹配、生成报销项目等。需要进行分类报销。

### 报销类型
- 出差报销
- 采购报销

### 发票类型
- 高铁票
- 飞机票
- 网约车发票
- 出租车发票
- 增值税专用发票
- 增值税普通发票
- 通用机打发票
- 定额发票
- 采购发票
- 其他

## 方案（待确认）

### 数据模型改动

**`expense_reimbursement` 表** — 新增 `reimbursement_type` 字段：
```sql
ALTER TABLE expense_reimbursement ADD COLUMN reimbursement_type TEXT DEFAULT '出差报销';
```

可选值：`出差报销`（默认）| `采购报销`

**`expense_invoice` 表** — `invoice_type` 字段已存在，OCR 识别时会自动填值。无需改表。

### API 改动

| 接口 | 改动 |
|------|------|
| `POST /api/reimbursements` | body 增加 `reimbursement_type` 字段 |
| `GET /api/reimbursements` | 增加 `type` 查询参数（过滤报销类型） |
| `GET /api/reimbursements/<id>` | 返回数据中增加 `reimbursement_type` |
| `PUT /api/reimbursements/<id>` | 支持更新 `reimbursement_type` |

### UI 改动（`records.html`）

1. **报销项列表**：增加「类型」列，新建报销项弹窗增加报销类型下拉选择，筛选栏增加报销类型下拉
2. **报销项详情展开区**：显示报销类型 badge（可点击切换，仅草稿状态可改）
3. **待整理区**：顶部增加「报销类型」标签页切换，按报销类型过滤

### 涉及文件

```
app/expense_db.py              — 数据库层支持类型
app/routes/expense.py          — API 支持类型
app/templates/expense/records.html — UI（核心改动）
```
