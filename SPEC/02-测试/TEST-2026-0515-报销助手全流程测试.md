## 修复记录

### Bug: 关键词搜索失效
- **发现时间**：2026-05-15
- **根因**：前端 `loadRecords()` 读取了 keyword 但从未拼进 fetch URL；后端 `get_all_reimbursements()` 不支持 keyword 参数
- **修复方案**：前端拼 URL 参数，后端 SQL 加 `WHERE (r.reimbursement_no LIKE ? OR r.title LIKE ?)`
- **涉及文件**：`app/expense_db.py`、`app/routes/expense.py`
- **状态**：已修复

### Bug: OCR 上传超时
- **发现时间**：2026-05-15
- **根因**：`recognize_file` + `recognize_payment` 顺序执行，图片 OCR 每次 ~19s，两次 = 40s+
- **修复方案**：两个 OCR 用 `threading.Thread` 并行执行
- **涉及文件**：`app/routes/expense.py`
- **状态**：已修复

### Bug: 页面风格不统一
- **发现时间**：2026-05-15
- **根因**：`records.html` 用标准 Bootstrap 卡片，与 `utils/` 深色风格不一致
- **修复方案**：三处卡片改为 `rgba(255,255,255,0.05)` 深色半透明风格
- **涉及文件**：`app/templates/expense/records.html`
- **状态**：已修复
